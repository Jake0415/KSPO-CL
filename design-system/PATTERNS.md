# 레이아웃 & 인터랙션 패턴

> 새 화면을 설계할 때 우선 이 패턴 중 하나를 골라서 시작.

---

## 패턴 1: List → Detail (가장 많이 쓰임)

**사용처:** 데이터 소스 목록, 사용자 목록, 게시물 목록 등

```
┌───────────────────────────────────────────┐
│ Page header (h1 + subtitle + 주요 액션)   │
├───────────────────────────────────────────┤
│ Filter bar (검색 / 셀렉트 / 토글)         │
├───────────────────────────────────────────┤
│ Table (또는 Card grid 토글)               │
│  - 행 클릭 → 상세 페이지 이동             │
└───────────────────────────────────────────┘
```

**핵심:**
- 검색 인풋 좌측 (300–360px)
- 우측에 `btn-primary` "새 ___" 단 1개
- 정렬/필터/뷰 토글은 검색 우측에 그룹화
- 페이지네이션은 테이블 하단 / 카드 하단

## 패턴 2: Detail with Side Panel

**사용처:** 로그 상세, 알림 상세, 비교 뷰

```
┌────────────────────────────┬──────────────┐
│ Main content (1fr)         │ Side (480px) │
│                            │ - 메타 정보   │
│                            │ - 코드 블록   │
│                            │ - 액션        │
└────────────────────────────┴──────────────┘
```

**핵심:**
- 사이드 패널은 목록 행 클릭 시 열리고, 다른 행 클릭 시 컨텐츠만 교체
- 닫기 버튼 ✕ 좌상단
- ESC 또는 외곽 클릭으로도 닫힘

---

## 패턴 3: Wizard (다단계 생성)

**사용처:** 신규 등록, 가입, 큰 설정

```
┌──────────────┬──────────────────────────┐
│ Step rail    │ Step content (card)      │
│ 1. ●─        │   …                      │
│ 2. ●─        │                          │
│ 3. ○─        │   ┌──────────────────┐   │
│ 4. ○         │   │ [이전]    [다음] │   │
└──────────────┴──┴──────────────────┴────┘
```

**핵심:**
- 좌측 스텝 레일 260px
- 마지막 단계는 항상 "검토 / 요약"
- 다음 단계로 이동 전 검증 통과 필수
- 취소는 topbar 우측 ghost 버튼

## 패턴 4: Dashboard (KPI + 차트 + 활동)

```
┌───────────────────────────────────────┐
│ KPI 4-card row (각 1fr, gap 16)       │
├───────────────────────────────────────┤
│ Big chart (2fr)    │ Side widget (1fr)│
├────────────────────┴──────────────────┤
│ Activity feed / 최근 실행 (full)      │
└───────────────────────────────────────┘
```

**핵심:**
- KPI: 라벨 / 큰 숫자 / 작은 트렌드
- 차트: 단색 라인 + soft area
- 활동 피드는 5–8개만, "전체 보기" 링크

---

## 패턴 5: Settings / Tabbed Detail

```
┌───────────────────────────────────────┐
│ Object header (이름/상태 + 액션)       │
├───────────────────────────────────────┤
│ Tabs ─────────────                    │
├───────────────────────────────────────┤
│ Tab content                           │
└───────────────────────────────────────┘
```

**핵심:**
- 객체 헤더는 큰 제목 + 메타 (URL, 담당자, 마지막 실행 등)
- 탭 4–6개가 적정. 그 이상이면 좌측 sub-nav로 변경
- 각 탭은 독립 페이지처럼 다룸 (URL fragment)

## 패턴 6: Auth (Login / Sign-up)

```
┌──────────────────┬────────────────────┐
│ Brand panel      │ Form panel         │
│ (그라디언트 X,    │ - 로고 (모바일만)   │
│  단색 + 일러스트  │ - 제목 / 설명       │
│  / 통계 인용)    │ - 폼               │
│                  │ - 푸터 링크         │
└──────────────────┴────────────────────┘
```

**핵심:**
- 좌측 브랜드 패널은 데스크탑만 표시 (≥1024)
- 폼 max-width 360
- "기억하기 / 비밀번호 찾기"는 폼 아래 한 줄

## 인터랙션 패턴

### Loading
- 인라인: `<svg class="spin">` (16px)
- 페이지 전체: 스켈레톤 카드 (테이블의 경우 4–6행)
- 절대 spinner 단독으로 큰 영역 가리지 말 것

### Empty
- 빈 상태는 항상 행동 유도 1개 포함
- "아직 ___이(가) 없습니다" → 한국어 자연스러운 표현

### Error
- 인라인 폼 오류: 필드 아래 12px / danger 텍스트
- 전체 오류: danger-soft 배경 + danger 보더 + 메시지 + 재시도 버튼
- 토스트는 일시적인 오류만 (3초)

### Confirmation (위험 액션)
- 삭제, 비활성화 등은 modal 확인 필수
- "정말 ___ 하시겠습니까?" + 결과 설명 + [취소] [확인 destructive]

### Inline editing
- 클릭하면 input으로 변신, blur/Enter로 저장
- 저장 성공 시 1초 success-soft 배경 펄스

### Tooltip
- hover 후 600ms 지연
- 다크 배경 (#020618), 흰 텍스트 12px
- 화살표 6px

### Search
- 디바운스 200ms
- 결과 없을 시 "'___' 검색 결과가 없습니다" + 클리어 버튼

## 정보 밀도 가이드

| 페이지 유형 | 밀도 |
|---|---|
| 어드민 테이블 | 높음 (행 높이 48) |
| 대시보드 | 중간 (카드 사이 16, 카드 패딩 20) |
| 폼 | 낮음 (필드 사이 18, 라벨/인풋 6) |
| 마케팅 | 매우 낮음 (사용 안 함) |

---

## 페이지 전환

- 같은 컨텍스트(탭 전환): instant
- 다른 페이지(메뉴 이동): scroll-to-top + 페이드 200ms
- 모달 / 드로어: slide + fade 160ms

---

## 키보드

- `⌘K` / `Ctrl+K` — 글로벌 검색
- `?` — 단축키 도움말 모달
- `j/k` — 테이블 행 네비게이션
- `Enter` — 선택 행 상세 이동
- `Esc` — 모달 / 드로어 / 검색 닫기
- 폼: `⌘Enter` / `Ctrl+Enter` 로 제출
