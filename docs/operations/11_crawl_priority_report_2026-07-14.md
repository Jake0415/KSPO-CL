## 판단 결과 — 투자 우선순위

### 🥇 1순위: www.ksponco.or.kr **심층 완전 크롤**
- **왜:** 시민 질문의 최대 비중(수영장·경기장·주차·요금·예약·프로그램)이 전부 이 도메인.
  평가셋 B/C/D 25문항의 사실상 정답 출처.
- **현재 공백:** 811페이지가 있지만 대부분 **목록/안내 페이지**이고, 실제 **요금·시간·
  시설 상세는 "온라인예약시스템"(JS)** 뒤에 있어 부분 수집. C2(요금)·B(시설상세) 실패의 근인.
- **실현성:** 브라우저 렌더링(use_playwright) + 예약시스템 URL 패턴 확보로 상세 페이지
  수집 가능. **ROI 최고.**

### 🥈 2순위: 국민체력100 **안내 콘텐츠 출처 확보**
- **왜:** 시민 관심 매우 높음(G 카테고리 5문항: 측정·비용·운동처방·인증서·센터).
- **현재 공백:** 전용 사이트 nfa=**예약전용/로그인벽**(자동수집 불가), 본사엔 게시판 언급만.
  운동처방·인증서·측정센터 목록의 **안내형 페이지가 코퍼스에 사실상 없음.**
- **실현성:** (a)안내가 공개된 다른 URL(예: 지역 측정센터 페이지) 조사, (b)없으면
  KSPO에 공개 안내 페이지 요청, (c)핵심 사실은 known-facts에 큐레이션(무료·예약일 이미 반영).
