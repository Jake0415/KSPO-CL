# 시작 URL 개선 적용 준비

상태: 코드 및 마이그레이션 준비. 운영 적용·배포는 실행하지 않음.

## DB 변경과 기존 데이터

0009는 domains.start_url TEXT NULL 컬럼만 추가한다. 기존 행은 NULL이며 pages,
crawl_jobs, board_source, 첨부 파일, Sonar MongoDB, Qdrant 데이터를 변경하지 않는다.
ALTER TABLE은 짧은 테이블 잠금이 필요하므로 장기 트랜잭션 여부를 확인한다.
마이그레이션은 재수집을 실행하지 않는다. 전체 수집을 별도로 실행하면 기존 정책에 따라
사이트 데이터를 초기화하므로, DB 마이그레이션과 전체 수집은 구분해야 한다.

## 적용 순서 (검토용, 아직 실행하지 않음)

1. DB 백업과 현재 alembic revision 확인. 0008 이후 다른 migration이 있으면 revision 충돌 검토.
2. API/워커/웹이 같은 코드 버전을 사용하도록 배포 계획 준비.
3. 프로젝트 런타임에서 `alembic upgrade 0009` 실행. 애플리케이션 새 버전 시작 전에 수행.
4. 도메인 설정 화면에서 기본 시작 URL 지정. 국민체력100은
   https://nfa.kspo.or.kr/main.kspo 사용. NFA는 코드상 브라우저 모드 자동 적용.
5. 운영 전체 수집 전에 제한된 검증 환경에서 리다이렉션·메뉴·정제·등록 확인.

요청의 경로/쿼리는 CrawlJob.seed_urls에 작업별 저장하며 기본 도메인 설정을 덮어쓰지 않는다.
도메인만 입력한 요청과 정기 작업은 도메인의 start_url을 사용하고 미설정은 기존 루트를 사용한다.
NFA 미설정 기본값은 /main.kspo이다. 증분 수집도 같은 진입점 선택 규칙을 사용한다.
요청 URL의 fragment만 제거하며 path/query는 보존한다. 현재 parser는 80/443 포트만 지원한다.

## 전체 수집 보호

초기화 전에 진입 주소를 조회하고 HTTP 오류, 다른 호스트로 이동, 로그인 이동,
본문/탐색 요소 부족이면 작업을 중단한다. 성공 후 실제 수집에서 다시 접근하므로
사전 검증은 전체 수집의 원자적 교체나 무손실을 보장하지 않는다.
www 포함 여부 등 호스트가 달라지는 리다이렉션은 자동 허용하지 않고 별도 설정 검토가 필요하다.
기존 문서 URL/해시는 유지하며 final_url은 링크·첨부 상대 경로 해석에 사용한다.

## 복구

기존 앱으로 되돌릴 때 추가 nullable 컬럼을 남겨도 된다. 0009 downgrade는 start_url 설정만
삭제하며 수집 문서를 삭제하지 않는다. 불필요한 스키마 롤백은 피한다.
