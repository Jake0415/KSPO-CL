# Crawl Target Validation — sports.re.kr

- **대상:** https://www.sports.re.kr (sports.re.kr 전용 크롤러 `src/kspo_ingest/crawl/sports/`)
- **크롤 실행일:** 2026-07-08 · **리포트 작성일:** 2026-07-10
- **목적:** 발견된 모든 페이지/콘텐츠 유형에 대해 크롤링 전략(대상 여부·빈도)이 올바르게 배정됐는지 검증. 현재 분류가 옳다고 가정하지 않는다. 더 많이 크롤하는 것이 아니라 **의미있는 변경을 모두 포착하면서 불필요한 요청을 최소화**하는 것을 최적화 목표로 한다.

**Method:** 모든 분류를 **관측 데이터**(게시판별 게시일 신선도, unit-type 매핑, 실제 저장된 문서)에 대조해 검증. Ground truth = 시드 레지스트리(`seeds.py`, 34 distinct sources) + `patterns.py` unit-type 로직 + 수집된 738 문서. "현재 분류(Current)" = 크롤러의 실제 동작(`source_type` + `priority` 1/2/3). 크롤러 자체에는 빈도 스케줄러가 없어(수동 실행) "권장 빈도"는 메인 파이프라인의 cron 모델을 기준으로 제시.

> **Headline:** 시드 기반 대상 선정은 대체로 건전하다(list/search/download/auth 페이지가 올바르게 제외됨). 그러나 **priority ≠ frequency**: 여러 **동결 아카이브가 priority-2(中)**이고, 여러 **정적 페이지가 churny 게시판과 같은 "board refresh" 주기로 묶여** 있다. 증거 기반 핵심 발견: **priority 티어가 관측된 갱신 주기와 불일치**하는 소스가 약 8개.

## Part C — 오분류 진단 (증거 기반)

**정확히 분류된 것 (✅ 오분류 아님):**
- **Search/pagination pages** → `canonical_url()`가 pageNo/search/menu_seq 축소, 검색페이지 target 아님. ✅
- **Navigation(list) pages** → `boardView`만 문서화, `boardList` 문서 0건. ✅
- **Download endpoints** → 첨부 메타로만, 독립문서 아님. ✅
- **Auth pages(NICE)** → `is_auth_gated` 스킵. ✅
- **Static pages는 daily가 아님** → priority 3(低)로 올바르게 저빈도. ✅ (전형적 "static을 daily로" 오류 없음)

**🔴 실제 오분류 / 재검토 대상:**
1. **아카이브가 中빈도로 분류됨** — `스포츠동향아카이브`(b105, 이름 자체가 아카이브), `KISS미디어룸`(2021 이후 정지)이 priority 2(中). 관측상 last365d=0. → **"archives treated as frequently changing" 오분류.** 권장 Monthly/On-demand.
2. **동결 게시판이 高빈도** — `행사안내`(b55) priority 1(高)이나 최신글 2023-10-16(2년 정지). → 과분류. 권장 Monthly(또는 원본 게시판 이동 여부 조사).
3. **활성 게시판이 中빈도** — `스포츠 현안과 진단`(b93) last90d=4로 활성인데 priority 2. → prio 상향(Daily/Weekly).
4. **시간민감 bid가 中빈도 + 날짜 결함** — `입찰정보`는 마감기한이 있어 Daily여야 하나 priority 2이고 날짜 추출 0%. → 분류·파서 동시 수정.
5. **FAQ를 board로 취급** — b54 FAQ는 상세페이지 아닌 아코디언 Q&A 가능성(0건 추출). board 페이지네이션 전략 부적합 가능. → 재검토.
6. **VOC를 크롤 target으로 등록** — 민원/비정형 데이터가 지식베이스 부적합 가능. 내용 확인 후 On-demand/Never 결정.

**Never-crawl (확정):** NICE 인증벽(`checkplusopen.do`), fileDownAct 독립수집.
**Navigation-only (확정):** `boardList.do`, GNB/메뉴 링크, `fnGoPage` 페이저.
