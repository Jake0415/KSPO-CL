# 경주데이터(kcycle/kboat) 수집 — 보류 기록

**일시:** 2026-07-11 · **상태:** 보류(deferred). 수집 여부·범위는 추후 결정.

## 요약
- kcycle(경륜)/kboat(경정)의 **경주 "지식" 페이지(규칙·가이드·소개)는 이미 적재됨**(kcycle 41 pages INDEXED).
- **경주 "카드/결과/배당" 라이브 데이터**는 SPA + 지연 AJAX로 로드되어 정적/Playwright 기본 렌더로는 로딩 셸만 나옴(한글 2%). 실 API는 JS 번들이 런타임 생성 → **브라우저 네트워크 캡처로 XHR 엔드포인트를 잡아야** 접근 가능.
- 라이브 데이터는 **transactional**(매 경주일 갱신·대량·수치표)이라 벡터 지식DB 적합성 낮음 → 실시간 API 서빙이 아키텍처상 적합. 넣을 경우 **범위 선별 필수**.

## 대상 URL (기록)

### kcycle (경륜) — https://www.kcycle.or.kr
**이미 적재된 지식 페이지 (프로세이지):**
- `/guide/learn/racerule` — 경주규칙 안내
- `/guide/enjoy/racecard` — 출주표 보는법
- `/guide/about/raceprogress` — 경주진행과정
- `/guide/learn/racetactics` — 경륜전법 소개

**미수집 라이브 데이터 (SPA/AJAX, 보류):**
- `/race/card/decision/{year}/{round}/{race}` — 확정 출주표(경주카드). 예: `/race/card/decision/2026/28/1`
- `/race/card/undecided` — 미확정 출주표
- `/race/card/jisoo` — 지수
- `/race/dividendrate/decision` , `/race/dividendrate/final` — 배당률
- `/race/info` — 종합경주정보
- `/race/judge/blackbox` — 심판(블랙박스)
- `/main/race` , `/main/race/result` — 경주결과
- `/broadcast/racevideo` — 경주영상(별도 미디어)

### kboat (경정) — https://www.kboat.or.kr
- kcycle와 동일 CMS 구조 추정(같은 "스피드온" 통합). 경주일정/출주표/결과/배당이 동일하게 SPA/AJAX 로드로 추정. 실제 경로는 수집 결정 시 네트워크 캡처로 확인 필요.

## 수집하려면 필요한 작업 (추후)
1. 브라우저 네트워크 캡처(Playwright + read_network)로 `/race/...` 페이지 렌더 시 발생하는 **XHR/JSON API 엔드포인트** 확보.
2. 해당 API 직접 호출 → JSON 파싱 → 문서화.
3. **범위 결정**: 경주일정(schedule) / 선수 프로필(상대적 안정) / 결과 / 배당(라이브) 중 무엇을 넣을지. 라이브 배당·결과는 벡터DB 부적합 → 제외 권장.

## 판단 메모
- 챗봇에 필요한 "경륜/경정이 무엇이고 어떻게 진행되나"는 이미 guide 페이지로 커버됨.
- 라이브 경주 데이터는 "지식"이 아니라 "실시간 조회 대상" → 넣는다면 선수 프로필·경주일정 등 **준안정 데이터만 선별**하는 게 합리적.
