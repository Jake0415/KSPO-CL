## 1. 개요

### 1.1 도입 배경

국민체육진흥공단(KSPO)은 본사이트(`www.kspo.or.kr`)와 다수의 패밀리 사이트를 통해 사업 공고·보도자료·사업 안내·통계 등 다양한 공개 콘텐츠를 운영한다. 그러나 콘텐츠가 여러 게시판·하위 사이트에 분산되어 있어, 사이트 내 검색·FAQ만으로는 일반 국민이 원하는 정보를 신속히 찾기 어렵다.

KSPO는 1차 민원 응대 자동화를 위해 메인 사이트(`kspo.or.kr`) 위젯 형태의 Tiledesk 기반 챗봇 도입을 계획하고 있으며, 이 챗봇이 정확한 답변과 출처(URL·첨부)를 제시하려면 KSPO의 공개 콘텐츠가 LLM 검색에 적합한 형태(벡터 DB)로 정제되어 있어야 한다.

본 시스템은 그 KB(Knowledge Base) 적재 파이프라인을 책임진다 — KSPO 공개 콘텐츠를 자동 수집·정제·임베딩하여 Tiledesk가 검색하는 Qdrant에 적재한다.

### 1.2 도입 목표 (한 줄)

KSPO 본사이트·패밀리 사이트의 공개 콘텐츠를 자동으로 수집·정제·벡터화하여 Tiledesk 챗봇이 검색하는 Qdrant 벡터 DB에 지속 적재한다.

### 1.3 기존 시스템과의 관계

| 시스템 | 본 시스템과의 관계 |
|---|---|
| KSPO 본사이트·패밀리 사이트 자체 검색 | **병행 유지** — 본 시스템은 콘텐츠를 외부에서 크롤로 수집할 뿐, 자체 검색을 대체·중단하지 않음 |
| KSPO 기존 FAQ | **병행 유지** — 챗봇 도입 후에도 FAQ 메뉴는 별도로 유지 (§9.3 #10 추적) |
| Tiledesk 챗봇 (신규 도입 예정) | 본 시스템 KB의 **유일한 소비자**. Direct 모드 적재 — 본 시스템은 챗봇 호출 안 함 |

### 1.4 성공 기준 (KPI)

> **수치 상태 표기**: "(확정)"이 붙은 행만 PRD에서 확정. 나머지 권장 목표(90/95/7일)는 **§9.3 #2** 로 추적되며 운영 1개월 측정값 기반으로 합의·조정한다. KPI 항목·측정 방법 자체는 PRD에서 모두 확정.

| KPI | 측정 방법 | 권장 목표 | 측정 주기 |
|---|---|---|---|
| **적재 커버리지** | 등록 도메인의 공개 페이지 중 INDEXED 비율 | ≥ 90% | 주 1회 (incremental 직후) |
| **적재 신선도** | 페이지 갱신 시점 ↔ Qdrant 재적재 시점 차이 | ≤ 7일 | 주 1회 |
| **Job 성공률** | `crawl_jobs.status='SUCCESS'` 비율 | ≥ 95% | 일 1회 |
| **월 LLM 비용** | `llm_usage` 누계 | ≤ 150,000원 (확정) | 분 단위 모니터링 + 월 보고 |
| (참고) **챗봇 1차 해결률** | Tiledesk 측 별도 측정 | — | 월 1회 (Tiledesk 측 책임) |

**확정 절차**:
- KPI 항목·측정 방법은 본 PRD에서 **확정**
- 권장 목표 수치는 운영 1개월 내 **KSPO 측정값 기반으로 합의·조정**
- 미달 시 운영 조치: 도메인 추가·refine 프롬프트 조정·청킹 파라미터 검토
