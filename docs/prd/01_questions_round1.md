## 2. 후속 질문 (PRD 작성 전·중에 답 필요)

### 2.1 프록시 (E-20에서 파생)

| 항목 | 결정 (round 1, 2026-05-07) |
|---|---|
| **환경변수 이름** | `HTTPS_PROXY` (Linux 표준 — openai SDK·httpx 자동 인식). 보조 `HTTP_PROXY`, `NO_PROXY` |
| 프록시 **호스트:포트 값** | 운영 시 `.env`에 KSPO 인프라팀 제공값 입력. `.env.example`에는 placeholder. **메커니즘 확정** ✓ |
| **인증 방식** | 인증 없음 (anonymous) |
| **TLS 인스펙션** | 없음 — 프록시는 CONNECT만 중계 (사내 root CA 마운트 불필요) |
| 허용 **화이트리스트** | `api.openai.com` 만 허용 (인프라팀 측 정책) |
| 크롤 outbound | OpenAI만 프록시 경유, 크롤(KSPO 본사이트·패밀리)은 **사내망 직접 접근**. `NO_PROXY`로 분리 |
| **`NO_PROXY` 기본값** | `localhost,127.0.0.1,postgres,redis,qdrant,host.docker.internal` + Admin 등록 KSPO 도메인 |
| **시작 시 검증** | `OPENAI_API_KEY` 있고 `HTTPS_PROXY` 비었으면 warning 로그 (error 아님) |

### 2.2 비용 통제 (F-25에서 파생)

| 항목 | 결정 |
|---|---|
| **임계 단위** | 월누계만 관리 (일 임계 없음) |

| **환율·가격 갱신** | 자동 회수는 Tier 2로 보류. round 1 단계는 하드코딩 또는 수동 PR |
| **카드 소진 시 운영 명세** | 런북 B.2를 시나리오 2종으로 분기 (B.2.A 키 무효 / B.2.B 카드 소진). `_appendix.md` §B.2 갱신, `05_devops_ops.md` §5.7 알림표에 "월 누계 80%" 행 추가, "일일 비용" 행 제거 ✓ |
