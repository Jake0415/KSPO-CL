# M1.T1.5 — Admin React UI 도메인 페이지 (List + New + Detail)

## Goal

T0.4 스캐폴딩 위에 도메인 페이지 3종(`/domains`, `/domains/new`, `/domains/:id`)과 로그인 페이지(`/login`)를 실제 동작 구현. T1.3 API + T1.4 인증을 결선. design-system 컴포넌트(`btn`, `card`, `table`, `input`, `badge`)만 사용.

## v2.1 시각 어휘 (절대 위반 금지)

- Primary `#155DFC`, 카드 radius 12, 보더 `#E2E8F0`
- 폼: height 36px, radius 8, focus halo 3px (`design-system/COMPONENTS.md`)
- shadow는 modal/dropdown/toast에만
- 상태 표시: 컬러 + 아이콘 + 텍스트 3중

## 라이브러리 결정 (Lite 정신 반영)

**shadcn CLI를 사용하지 않고**, design-system의 Tailwind 토큰 기반 클래스를 활용해 컴포넌트를 직접 작성. 이유: shadcn CLI는 `tailwind.config.js`를 자동 수정하고 `lib/utils.ts`(`cn`) 같은 보일러플레이트를 생성하는데, 본 프로젝트는 `design-system/tokens/tailwind.config.js`를 단일 진실원으로 유지해야 함(CLAUDE.md 절대 금지 §10).

| 컴포넌트 | 채택 | 비채택 + 이유 |
|---|---|---|
| Button / Card / Input / Textarea / Checkbox / Table / Badge | **자체 작성** (`design-system/COMPONENTS.md` 클래스 매핑) | shadcn CLI — config 자동 변형 위험 |
| ConfirmDialog (destructive 확인) | **`@radix-ui/react-dialog`** (헤드리스, 접근성 보장) | 자체 작성 — `aria-modal`/focus trap 직접 구현은 사고 위험 |
| Toast | **자체 작성 (`useToast` + Provider, ~80 LOC)** | sonner — 의존성 1개 절약, 디자인 토큰 100% 일치 보장 |
| Checkbox 시각 | **자체 `<input type="checkbox">` + Tailwind** | `@radix-ui/react-checkbox` — 네이티브로 충분, 의존성 절약 |

**최종 frontend 신규 의존성**: `@radix-ui/react-dialog`만. `sonner`·`@radix-ui/react-checkbox` 제거.

```tsx
export default function Login() {
  const [u, setU] = useState("");
  const [p, setP] = useState("");
  const [err, setErr] = useState<string | null>(null);
  const navigate = useNavigate();

  async function submit(e: FormEvent) {
    e.preventDefault();
    setErr(null);
    const body = new URLSearchParams({ username: u, password: p });
    const res = await fetch("/api/auth/login", {
      method: "POST",
      credentials: "include",
      headers: { "Content-Type": "application/x-www-form-urlencoded" },
      body,
    });
    if (res.ok) {
      navigate("/", { replace: true });
    } else {
      setErr("아이디 또는 비밀번호가 올바르지 않습니다.");
    }
  }

  return (
    <div className="min-h-screen flex bg-bg">
      {/* 좌측 브랜드 패널 */}
      <div className="hidden md:flex w-1/2 bg-primary items-center justify-center">
        <div className="text-white">
          <div className="text-3xl font-bold">kspo-ingest</div>
          <div className="mt-2 text-sm opacity-80">운영 콘솔</div>
        </div>
      </div>
      {/* 우측 폼 */}
      <form onSubmit={submit} className="flex-1 flex items-center justify-center">
        <div className="w-[360px] space-y-4">
          <h1 className="text-2xl font-semibold">로그인</h1>
          <Input label="아이디" value={u} onChange={e => setU(e.target.value)} required autoFocus />
          <Input label="비밀번호" type="password" value={p} onChange={e => setP(e.target.value)} required />
          {err && <div className="text-sm text-red-600">{err}</div>}
          <Button type="submit" variant="primary" className="w-full">로그인</Button>
        </div>
      </form>
    </div>

}
```

### `<AuthGuard>` — 보호 라우트 래퍼

```tsx
export function AuthGuard({ children }: { children: ReactNode }) {
  const { data, isLoading, isError } = useQuery({
    queryKey: ["session"],
    queryFn: async () => {
      const r = await fetch("/api/auth/me", { credentials: "include" });
      if (r.status === 401) throw new Error("unauthenticated");
      return r.json() as Promise<{ username: string; via: string }>;
    },
    retry: false,
  });
  if (isLoading) return <FullPageSpinner />;
  if (isError || !data) return <Navigate to="/login" replace />;
  return <>{children}</>;
}
```

### Toast / ConfirmDialog

**Toast (자체 구현, ~80 LOC)** — `design-system/PATTERNS.md` 토스트 패턴 참조 (top-right, autodismiss 4s, success/error/info 3종, 컬러+아이콘+텍스트 3중 신호):

```tsx
// components/ui/ToastProvider.tsx
type Toast = { id: string; kind: "success" | "error" | "info"; msg: string };
const ToastCtx = createContext<{ push: (t: Omit<Toast, "id">) => void }>(null!);

export function ToastProvider({ children }: { children: ReactNode }) {
  const [items, setItems] = useState<Toast[]>([]);
  const push = useCallback((t: Omit<Toast, "id">) => {
    const id = crypto.randomUUID();
    setItems(s => [...s, { ...t, id }]);
    setTimeout(() => setItems(s => s.filter(x => x.id !== id)), 4000);
  }, []);
  return (
    <ToastCtx.Provider value={{ push }}>
      {children}
      <div className="fixed top-4 right-4 z-50 flex flex-col gap-2">
        {items.map(t => (
          <div key={t.id} role="status" aria-live="polite"
               className={`card shadow-md px-4 py-3 flex items-center gap-2
                 ${t.kind === "success" ? "border-l-4 border-l-green-600" :
                   t.kind === "error"   ? "border-l-4 border-l-red-600"   :
                                          "border-l-4 border-l-primary"}`}>
            {t.kind === "success" && <CheckCircle size={16} className="text-green-600" />}
            {t.kind === "error"   && <AlertCircle size={16} className="text-red-600" />}
            {t.kind === "info"    && <Info size={16} className="text-primary" />}
            <span className="text-sm">{t.msg}</span>
          </div>
        ))}
      </div>
    </ToastCtx.Provider>
  );
}
export const useToast = () => useContext(ToastCtx);
```

> `App.tsx`에서 `<QueryClientProvider>` 안쪽에 `<ToastProvider>` 감싸기. 사용: `const { push } = useToast(); push({ kind: "success", msg: "등록됨" })`.

**ConfirmDialog** — `@radix-ui/react-dialog` 래핑. destructive 확인 시 사용자가 호스트명 입력 → 일치할 때만 "삭제" 버튼 활성화:

```tsx
import * as Dialog from "@radix-ui/react-dialog";

export function ConfirmDialog({
  open, onOpenChange, title, description, confirmText, requireMatch, onConfirm,
}: {
  open: boolean; onOpenChange: (o: boolean) => void;
  title: string; description: string; confirmText: string;
  requireMatch?: string;          // 입력 일치 필요 시(예: 호스트명)
  onConfirm: () => void;
}) {
  const [typed, setTyped] = useState("");
  const canConfirm = requireMatch ? typed === requireMatch : true;
  return (
    <Dialog.Root open={open} onOpenChange={onOpenChange}>
      <Dialog.Portal>
        <Dialog.Overlay className="fixed inset-0 bg-black/40" />
        <Dialog.Content className="card shadow-md fixed top-1/2 left-1/2 -translate-x-1/2 -translate-y-1/2 w-[420px] p-6">
          <Dialog.Title className="text-lg font-semibold">{title}</Dialog.Title>
          <Dialog.Description className="mt-2 text-sm text-ink-muted">{description}</Dialog.Description>
          {requireMatch && (
            <input className="input mt-4 w-full" placeholder={requireMatch}
                   value={typed} onChange={e => setTyped(e.target.value)} />
          )}
          <div className="mt-6 flex justify-end gap-2">
            <Dialog.Close asChild><button className="btn btn-ghost">취소</button></Dialog.Close>
            <button className="btn btn-destructive" disabled={!canConfirm} onClick={onConfirm}>
              {confirmText}
            </button>
          </div>
        </Dialog.Content>
      </Dialog.Portal>
    </Dialog.Root>
  );
}
```
