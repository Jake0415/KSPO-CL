# M0.T0.2 — Docker + Compose (6 서비스) + Alembic 초기

## Goal

`docker/`에 Dockerfile 4종(api, worker, migrations, **web**) + nginx 설정을 만들고, `docker-compose.yml`로 **6 서비스**(nginx · api · worker · postgres · redis · qdrant)를 정의. Alembic 셋업과 빈 초기 마이그레이션(`0001_init`).

`docker compose up -d`(migrations profile 제외) 시 5 서비스(api/worker/postgres/redis/qdrant) healthy. **nginx는 `web/dist`가 만들어지는 M0.T0.4 머지 후 healthy** — 본 Task에선 빌드 가능 상태까지(설정·placeholder).

## v2.1 핵심 변경 사항

- **6 서비스**: lite v2.0(5개) + `nginx` 추가(정적자산 + 리버스 프록시)
- **`qdrant`** 서비스 — 개발/파일럿 전용. 정식 운영 전환 시 제거(→ 5 서비스)
- **`Dockerfile.web`** 추가 — Node 20 빌드 + nginx multi-stage
- **`docker/nginx/nginx.conf`** — SPA fallback + `/api/` `/files/` reverse proxy
- 모든 컨테이너 **`TZ=Asia/Seoul`** 일괄
- `api`/`worker`만 사내 프록시 환경변수(`HTTPS_PROXY`/`HTTP_PROXY`/`NO_PROXY`) 주입

## Spec

### Dockerfile.api

`docs/design/05_devops_ops.md §5.3` 참조.

```dockerfile
FROM python:3.12-slim
ENV PYTHONUNBUFFERED=1 PYTHONDONTWRITEBYTECODE=1 \
    PIP_NO_CACHE_DIR=1 PIP_DISABLE_PIP_VERSION_CHECK=1 \
    TZ=Asia/Seoul
RUN apt-get update && apt-get install -y --no-install-recommends \
    build-essential libxml2 libxslt1.1 curl tzdata && \
    ln -fs /usr/share/zoneinfo/$TZ /etc/localtime && \
    rm -rf /var/lib/apt/lists/*
WORKDIR /app
COPY pyproject.toml /app/
RUN pip install -U pip && pip install -e .[api]
COPY src /app/src
COPY migrations /app/migrations
EXPOSE 8080
CMD ["uvicorn","kspo_ingest.api.main:app","--host","0.0.0.0","--port","8080"]
```

### Dockerfile.worker / Dockerfile.migrations

같은 베이스. CMD만 다름.
- `Dockerfile.worker` → `python -m kspo_ingest.tasks.run_worker`
- `Dockerfile.migrations` → `alembic upgrade head` (1회 실행)

`run_worker.py`는 placeholder — `print("worker placeholder"); time.sleep(60)` 루프(실제 ARQ 워커는 M2.T2.4).

### Dockerfile.web ⭐ v2.1

```dockerfile
# 1) build SPA
FROM node:20-alpine AS build
WORKDIR /app
COPY web/package.json web/package-lock.json* ./
RUN npm ci || npm install
COPY web/ ./
RUN npm run build || mkdir -p dist && cp -n dist/* /tmp/ 2>/dev/null || true
# T0.4 전: web/dist/index.html (placeholder) 사용
# T0.4 후: vite build → web/dist 생성

# 2) nginx serve + reverse proxy
FROM nginx:1.27-alpine
ENV TZ=Asia/Seoul
RUN apk add --no-cache tzdata && cp /usr/share/zoneinfo/$TZ /etc/localtime
COPY --from=build /app/dist /usr/share/nginx/html
COPY docker/nginx/nginx.conf /etc/nginx/nginx.conf
EXPOSE 80 443
```

> T0.4 머지 전엔 `web/package.json`이 없으므로 `npm ci || npm install` 단계가 무동작. T0.4 머지 후 정상 빌드.
> certs는 컨테이너 빌드 시 COPY하지 말고 compose volume mount(`/etc/nginx/certs:ro`)로만 주입 — self-signed 또는 사내 발급 증명서 교체 용이.

### docker/nginx/nginx.conf ⭐ v2.1

```nginx
worker_processes auto;
events { worker_connections 1024; }

http {
    include       mime.types;
    default_type  application/octet-stream;
    sendfile      on;
    keepalive_timeout 65;
    client_max_body_size 110M;          # 첨부 100MB + 여유

    gzip on;
    gzip_types text/plain text/css application/javascript application/json image/svg+xml;
    gzip_min_length 1024;

    upstream api_upstream { server api:8080; }

    server {
        listen 80 default_server;
        server_name _;

        # 정적 자산 (immutable)
        location /assets/ {
            root /usr/share/nginx/html;
            expires 1y;
            add_header Cache-Control "public, immutable";
        }

        # API 리버스 프록시
        location /api/ {
            proxy_pass http://api_upstream;
            proxy_set_header Host              $host;
            proxy_set_header X-Real-IP         $remote_addr;
            proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_set_header X-Request-Id      $http_x_request_id;
            proxy_read_timeout 120s;
        }

        # 첨부파일 공개 엔드포인트 (M3.T3.4)
        location /files/ {
            proxy_pass http://api_upstream;
            proxy_set_header Host $host;
            proxy_read_timeout 120s;
        }

        location /healthz { proxy_pass http://api_upstream; }
        location /readyz  { proxy_pass http://api_upstream; }
        location /docs    { proxy_pass http://api_upstream; }

        # SPA fallback — 모든 비-API 경로는 index.html
        location / {
            root /usr/share/nginx/html;
            try_files $uri $uri/ /index.html;
        }
    }
}
```

> TLS는 `ssl_certificate`·`ssl_certificate_key` 라인을 PRD §9.3 #5 결정 후 별도 PR에서 추가. 본 Task는 80만 listen.

### docker-compose.yml

`docs/design/05_devops_ops.md §5.1` 그대로 6 서비스. 핵심:

```yaml
name: kspo-ingest
services:
  nginx:
    build: { context: .., dockerfile: docker/Dockerfile.web }
    depends_on:
      api: { condition: service_started }
    ports: ["80:80"]
    volumes: [../docker/nginx/certs:/etc/nginx/certs:ro]
    environment: [TZ=Asia/Seoul]
    restart: unless-stopped

  api:
    build: { context: .., dockerfile: docker/Dockerfile.api }
    env_file: [../.env]
    depends_on:
      postgres: { condition: service_healthy }
      redis:    { condition: service_healthy }
    expose: ["8080"]                # 호스트 비노출 (nginx 경유만)
    volumes: [storage:/data]
    environment:
      - TZ=Asia/Seoul
      - HTTPS_PROXY=${HTTPS_PROXY}   # api/worker만 적용
      - HTTP_PROXY=${HTTP_PROXY}
      - NO_PROXY=${NO_PROXY}
    healthcheck:
      test: ["CMD","curl","-f","http://localhost:8080/healthz"]
      interval: 10s
      retries: 5
    restart: unless-stopped

  worker:
    build: { context: .., dockerfile: docker/Dockerfile.worker }
    env_file: [../.env]
    depends_on:
      postgres: { condition: service_healthy }
      redis:    { condition: service_healthy }
    volumes: [storage:/data]
    environment:
      - TZ=Asia/Seoul
      - WORKER_QUEUES=default,attach,bg
      - WORKER_CONCURRENCY=4
      - HTTPS_PROXY=${HTTPS_PROXY}
      - HTTP_PROXY=${HTTP_PROXY}
      - NO_PROXY=${NO_PROXY}
    restart: unless-stopped

  postgres:
    image: postgres:16-alpine
    env_file: [../.env]
    environment:
      POSTGRES_DB: ${POSTGRES_DB}
      POSTGRES_USER: ${POSTGRES_USER}
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
      TZ: Asia/Seoul
    volumes: [pgdata:/var/lib/postgresql/data]
    healthcheck:
      test: ["CMD-SHELL","pg_isready -U $$POSTGRES_USER -d $$POSTGRES_DB"]
      interval: 10s
    restart: unless-stopped

  redis:
    image: redis:7-alpine
    command: ["redis-server","--save","''","--appendonly","no"]
    volumes: [redisdata:/data]
    healthcheck: { test: ["CMD","redis-cli","ping"], interval: 10s }
    environment: [TZ=Asia/Seoul]
    restart: unless-stopped

  qdrant:                              # 개발/파일럿 전용
    image: qdrant/qdrant:latest
    volumes: [qdrant_data:/qdrant/storage]
    expose: ["6333"]                   # 호스트 비노출 (사내망 only)
    environment: [TZ=Asia/Seoul]
    restart: unless-stopped

  migrations:
    build: { context: .., dockerfile: docker/Dockerfile.migrations }
    env_file: [../.env]
    depends_on: { postgres: { condition: service_healthy } }
    profiles: ["migrations"]
    command: ["alembic","upgrade","head"]

volumes: { pgdata: {}, redisdata: {}, qdrant_data: {}, storage: {} }
networks:
  default: { name: kspo-ingest-net }
```

from sqlalchemy.orm import DeclarativeBase

NAMING = {
    "ix": "ix_%(table_name)s_%(column_0_N_name)s",
    "uq": "uq_%(table_name)s_%(column_0_N_name)s",
    "fk": "fk_%(table_name)s_%(column_0_name)s_%(referred_table_name)s",
    "pk": "pk_%(table_name)s",
    "ck": "ck_%(table_name)s_%(constraint_name)s",
