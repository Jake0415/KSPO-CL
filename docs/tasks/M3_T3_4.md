# M3.T3.4 — 첨부 메타데이터 적재 + `/files/{id}` 302 redirect (v2.0 Lite)

> **v2.0 Lite 정책 (2026-05-07 결정)** — 본 Task는 첨부 파일을 **다운로드/추출/임베딩하지 않는다**. 페이지 HTML에서 발견한 첨부 링크의 메타(URL/파일명/MIME)만 `attachments`에 저장하고, 챗봇은 `GET /files/{attachment_id}`로 `source_url`에 302 redirect. PDF/DOCX/XLSX/PPTX 추출, 100MB 상한, ARQ download task, 첨부 청크 임베딩은 모두 보류. 운영 후 챗봇 답변 품질이 부족하면 Tier 2로 추가 검토.
>
> 따라서 본 문서의 아래 Spec 중 다운로드·추출·청크·임베딩 항목은 모두 미구현 상태이며, 구현된 범위는 다음 두 가지로 축소된다:
> 1. `attach/discovery.py` + `attach/mime.py` — 페이지 HTML에서 첨부 링크 추출 (메타만)
> 2. `tasks/pipeline/extract_links.py` — 발견한 메타를 `attachments` 테이블에 upsert (`extraction_status='SKIPPED'`, `storage_path=''`)
> 3. `api/routers/files.py` — `GET /files/{id}` → `attachments.source_url` 302 redirect (인증 없음 — 챗봇 공개 화이트리스트)

## Goal (deprecated, 원래 spec)

T2.4의 `extract_links`가 페이지 본문에서 발견한 첨부 URL(`.pdf`/`.docx`/`.xlsx`/`.pptx`)을 다운로드 → 텍스트 추출 → `attachments` 행 생성 → 첨부 청크(T3.1) → 임베딩(T3.2) → Qdrant upsert(T3.3) 흐름 결선. 100MB 상한. HWP는 `extraction_status='SKIPPED'`. 챗봇이 사용자에게 첨부 다운로드 링크를 노출할 수 있도록 `GET /files/{attachment_id}` 공개 엔드포인트 제공.

**M3 종료 Task**.

## Spec

### 첨부 발견 (`discovery.py`)

```python
SUPPORTED_EXTS = {".pdf", ".docx", ".xlsx", ".pptx"}
SKIPPED_EXTS = {".hwp", ".hwpx"}                 # 첨부 메타만, 본문 추출 X
IGNORED_EXTS = {".zip", ".exe", ".jpg", ".png", ".gif", ".mp4"}      # OCR/이미지 미포함


@dataclass
class DiscoveredAttachment:
    source_url: str
    file_name: str
    ext: str                         # ".pdf" 등
    will_extract: bool               # SUPPORTED면 True, SKIPPED면 False, IGNORED면 발견 안 함


def discover_attachments(html: str, base_url: str) -> list[DiscoveredAttachment]:
    """
    1. selectolax로 모든 <a href> 수집
    2. urljoin(base_url, href) → 절대 URL
    3. URL의 path 끝 확장자 검사 (대소문자 무관)
    4. SUPPORTED → will_extract=True, SKIPPED → will_extract=False, IGNORED → 결과 제외
    5. file_name: URL path의 basename 또는 query에서 file_name= 파라미터 (KSPO 게시판 패턴)
    """
```

### 다운로더 (`downloader.py`)

```python
MAX_BYTES = 100 * 1024 * 1024      # 100MB


@dataclass
class DownloadResult:
    storage_path: Path
    file_hash: str                   # sha256 hex
    byte_size: int
    mime_type: str                   # response Content-Type


async def download(url: str, *, storage_root: Path, domain_id: int) -> DownloadResult:
    """
    1. httpx stream으로 응답 받음 — Content-Length 사전 검사 (있으면)
    2. 100MB 초과 시 AttachmentTooLarge 즉시 raise
    3. tmp 파일에 chunk(64KB)씩 쓰며 누적 크기 검사 — 초과 시 즉시 cancel + tmp 삭제
    4. sha256 계산 (스트리밍)
    5. {storage_root}/attachments/{domain_id}/{file_hash[:2]}/{file_hash}.{ext} 로 rename
    6. 동일 file_hash 파일이 이미 있으면 dedup (rename 대신 tmp 삭제 + 기존 path 반환)
    """
```

> **dedup**: `attachments` 테이블 UNIQUE(`domain_id`, `file_hash`)와 동기화. 같은 도메인에 같은 첨부가 여러 페이지에 인용되면 `attachments` row는 1개만 존재 — 페이지-첨부 N:M 정규화는 Tier 3 (`_appendix.md` §C).

### 추출기 (`extractors/*.py`)

각 추출기는 단일 인터페이스:

```python
def extract(path: Path) -> ExtractionResult:
    """returns ExtractionResult(text=..., status='OK'|'ERROR', error_message=None)."""


@dataclass
class ExtractionResult:
    text: str
    status: Literal["OK", "ERROR"]
    error_message: str | None
```

구현:
- **pdf.py** — `pypdf.PdfReader`. 페이지별 text 추출 + 페이지 경계는 `\n\n`. 암호화 PDF → `ERROR` (status, error_message="encrypted")
- **docx.py** — `python-docx.Document`. paragraphs + tables. 단락 경계 `\n\n`
- **xlsx.py** — `openpyxl.load_workbook(read_only=True)`. 시트별: `[시트명]\n` + 행은 `|` 구분. 빈 셀은 스킵
- **pptx.py** — `python-pptx.Presentation`. 슬라이드별: `[슬라이드 N]\n` + 모든 text frame

공통 후처리:
- 비가시 문자 제거
- `re.sub(r'\s+', ' ', ...)` 단락 경계만 `\n\n`로 보존
- 텍스트 길이 < 50자 → `ERROR` ("too_short_after_extraction") — 추출 실패 의심

### 라우터 (`router.py`)

```python
EXTRACTOR_BY_EXT = {
    ".pdf":  pdf.extract,
    ".docx": docx.extract,
    ".xlsx": xlsx.extract,
    ".pptx": pptx.extract,
}


def route(ext: str) -> Callable | None:
    return EXTRACTOR_BY_EXT.get(ext.lower())
```

### ARQ task (`tasks/pipeline/download_attachment.py`)

```python
async def download_attachment(ctx, *, job_id: int, page_id: int, source_url: str,
                              file_name: str, ext: str) -> None:
    s = ctx["session_factory"]()
    if await is_cancelled(s, job_id):
        return

    page = await s.get(Page, page_id)

    # 1) SKIPPED 확장자 (HWP) — 다운로드 자체를 안 함, attachments 메타만 기록
    if ext.lower() in SKIPPED_EXTS:
        att = Attachment(
            page_id=page_id, domain_id=page.domain_id, source_url=source_url,
            file_name=file_name, mime_type=_mime_for_ext(ext),
            file_hash=_hash_url(source_url),     # URL 기반 임시 hash
            storage_path="", extraction_status="SKIPPED",
        )
        s.add(att); await s.commit()
        return

    # 2) 다운로드
    try:
        dl = await ctx["downloader"].download(source_url, storage_root=settings.storage_root, domain_id=page.domain_id)
    except AttachmentTooLarge:
        # 100MB 초과 — 메타만 기록, 추출 안 함
        ...
        return
    except Exception as e:
        # 다운로드 실패 — extraction_status='ERROR'
        ...
        return

    # 3) attachments row upsert (UNIQUE: domain_id, file_hash)
    att = await upsert_attachment(s, page_id=page_id, domain_id=page.domain_id, dl=dl, file_name=file_name, source_url=source_url)

    # 4) 텍스트 추출
    extractor = route(ext)
    if extractor is None:
        att.extraction_status = "SKIPPED"; await s.commit()
        return

    result = extractor(dl.storage_path)
    att.extracted_text = result.text if result.status == "OK" else None
    att.extraction_status = result.status
    await s.commit()

    if result.status != "OK":
        return

    # 5) 첨부 청크 빌드 → 임베딩 → Qdrant upsert
    chunks = chunk_attachment(
        page_id=page_id, attachment_id=att.id, embedding_version=settings.embedding_version,
        file_name=file_name, parent_title=page.title, parent_posted_at=page.discovered_at,
        body_text=result.text,
    )
    chunk_ids = await upsert_chunks_meta(s, page_id, att.id, chunks)
    embedded = await embed_to_memory(s, chunk_ids, model=settings.openai_embed_model, job_id=job_id)
    await QdrantDirectAdapter().upsert_chunks(embedded)

    # 6) chunks.kb_status='OK', llm_usage 기록은 embedder가 자동
    await bump_stats(s, job_id, indexed=len(embedded))
```

> **queue_name="attach"**: 본 task는 별도 큐로 분리 — 다운로드가 페이지 fetch보다 느려 default 큐를 막지 않도록. 워커 동시성은 `WORKER_QUEUES=default,attach,bg` 환경변수로 제어 (T0.2에서 이미 정의).

### `/files/{id}` 공개 엔드포인트 (`api/routers/files.py`)

**인증 없음** (외부 챗봇이 사용자에게 노출할 다운로드 링크 — 화이트리스트). T1.4 `require_admin` 미적용.

```python
router = APIRouter(prefix="/files", tags=["files"])


@router.get("/{attachment_id}")
async def download_attachment_file(attachment_id: int, s: AsyncSession = SessionDep):
    att = await s.get(Attachment, attachment_id)
    if att is None or not att.storage_path:
        raise HTTPException(404, "attachment not found")
    path = Path(att.storage_path)
    if not path.is_file():
        raise HTTPException(410, "file removed")     # 파일 삭제됨 (운영 중 storage 청소 시)
    return FileResponse(
        path=path,
        media_type=att.mime_type or "application/octet-stream",
        filename=att.file_name or path.name,
    )
```

> **공개 노출 위험**: 첨부는 모두 KSPO 공개 자료(`docs/prd/03_stakeholders_scope.md` §3.3) 가정 — 비공개 자료는 크롤되지 않으므로 `/files/{id}` 공개로 안전. 공개자료 정책 위반 발견 시 운영자가 `attachments` 행 삭제 + storage 파일 삭제 SOP.
