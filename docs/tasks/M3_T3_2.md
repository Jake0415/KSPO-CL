## Spec

### OpenAI 임베딩 호출 (`openai_embed.py`)

```python
from openai import AsyncOpenAI
from tenacity import AsyncRetrying, stop_after_attempt, wait_exponential, retry_if_exception_type
from openai import APIConnectionError, APITimeoutError, RateLimitError


@dataclass
class EmbedBatchResult:
    vectors: list[list[float]]              # 입력 순서와 동일
    prompt_tokens: int                      # usage.prompt_tokens
    total_tokens: int                       # usage.total_tokens (= prompt_tokens for embeddings)


async def embed_batch(client: AsyncOpenAI, model: str, inputs: list[str]) -> EmbedBatchResult:
    """tenacity로 5회 재시도 (5xx/429/timeout). 401/400은 즉시 raise.

    OpenAI embeddings API: client.embeddings.create(input=inputs, model=model)
    응답 vectors는 inputs와 동일 순서 보장.
    """
    async for attempt in AsyncRetrying(
        stop=stop_after_attempt(5),
        wait=wait_exponential(multiplier=1, min=1, max=300),
        retry=retry_if_exception_type((APIConnectionError, APITimeoutError, RateLimitError)),
        reraise=True,
    ):
        with attempt:
            r = await client.embeddings.create(input=inputs, model=model)
            return EmbedBatchResult(
                vectors=[d.embedding for d in r.data],
                prompt_tokens=r.usage.prompt_tokens,
                total_tokens=r.usage.total_tokens,
            )
```

### 비용 (`cost.py`)

```python
# `cost.py`에 임베딩 가격 추가
PRICING_USD_PER_1M = {
    "gpt-5.4-mini":              {"prompt": 0.150, "completion": 0.600},
    "text-embedding-3-large":    {"prompt": 0.130, "completion": 0.0},   # 임베딩은 input only
}


def calc_embed_cost_usd(model: str, prompt_tokens: int) -> Decimal:
    rate = PRICING_USD_PER_1M.get(model)
    if rate is None: return Decimal("0")
    return (Decimal(prompt_tokens) * Decimal(str(rate["prompt"])) / Decimal("1000000")).quantize(Decimal("0.000001"))
```

> 가격 출처는 OpenAI 공식 페이지. 모델 추가 시 PR로 갱신 (자동 회수는 Tier 2).

### 부분 실패 fallback 시나리오

| 케이스 | 동작 |
|---|---|
| 96 청크 배치 호출 → 200 OK | 96개 모두 success |
| 96 청크 배치 호출 → 5xx + 5회 재시도 모두 실패 | 96개 1건씩 fallback 호출 |
| fallback 96회 중 95회 OK, 1회 실패 | 95 success, 1 ERROR |
| fallback 1건 호출 → 5회 재시도 모두 실패 | 해당 chunk ERROR, 다른 청크 영향 없음 |
| 401 Unauthorized | 즉시 raise (런북 B.2.A — Job FAILED) |
| 429 insufficient_quota | tenacity 재시도 5회 → 마지막에 raise (런북 B.2.B — Job FAILED) |

> **로그**: 본문 텍스트 미포함. `event=embed_batch_ok size=96 prompt=NNN cost_krw=NN.NN` / `event=embed_fallback chunk_id=... reason=...` / `event=embed_chunk_error chunk_id=...`.
