# M3.T3.1 — Chunker (2단 청킹 + 컨텍스트 헤더 + Deterministic ID)

## Goal

REFINED 페이지를 받아 (1) tiktoken으로 토큰 수 측정 → (2) >800 토큰이면 window split(target=600, overlap=80) / 그 외 단일 청크 → (3) 페이지 청크는 컨텍스트 헤더 1종 / 첨부 청크는 별도 헤더 → (4) `chunk_id_sha1` + `qdrant_point_id`(uuid5) 결정론적 생성 → (5) PG `chunks` PENDING upsert. 임베딩 호출은 T3.2.

## Spec

### 토크나이저 (`tokens.py`)

```python
import tiktoken
from functools import lru_cache


@lru_cache(maxsize=4)
def get_encoder(model: str = "cl100k_base"):
    """text-embedding-3-large는 cl100k_base 사용. 모델 추가 시 매핑 확장."""
    return tiktoken.get_encoding(model)


def count_tokens(text: str, encoder_name: str = "cl100k_base") -> int:
    return len(get_encoder(encoder_name).encode(text))
```

### 컨텍스트 헤더 (`header.py`) — `03_chunk_embed_qdrant.md` §3.3, §3.4

```python
@dataclass
class PageHeaderInput:
    title: str | None
    domain_host: str
    posted_at: datetime | None
    summary: str | None


def build_page_header(h: PageHeaderInput) -> str:
    """페이지 청크용 헤더. posted_at/summary 없으면 라인 생략."""
    lines = []
    if h.title: lines.append(f"[제목] {h.title}")
    lines.append(f"[도메인] {h.domain_host}")
    if h.posted_at: lines.append(f"[게시일] {h.posted_at.date().isoformat()}")
    if h.summary: lines.append(f"[요약] {h.summary}")
    return "\n".join(lines) + "\n\n— 본문 —\n"


@dataclass
class AttachmentHeaderInput:
    file_name: str
    parent_title: str | None
    parent_posted_at: datetime | None


def build_attachment_header(h: AttachmentHeaderInput) -> str:
    """첨부 청크용 별도 헤더 (`§3.4`)."""
    lines = [f"[첨부파일] {h.file_name}"]
    if h.parent_title: lines.append(f"[부모 게시글] {h.parent_title}")
    if h.parent_posted_at: lines.append(f"[게시일] {h.parent_posted_at.date().isoformat()}")
    return "\n".join(lines) + "\n\n— 본문 —\n"
```

### Window split (`window_split.py`)

분할 우선순위: `\n\n` (단락) > `\n` (줄) > `. ? !` (문장) > 어절(공백). target=600, overlap=80.

```python
def window_split(text: str, *, target: int, overlap: int) -> list[str]:
    """
    1) 본문을 단락 단위(\n\n)로 분할 → 누적 토큰 수가 target에 도달하면 청크 cut
    2) 한 단락이 target을 초과하면 줄(\n) 단위로 재분할
    3) 한 줄이 target 초과하면 문장(. ? !) 단위 (한국어는 마침표 + 공백 또는 문단 끝)
    4) 한 문장이 target 초과하면 어절(공백) 단위
    5) 청크 간 overlap 토큰 만큼 겹침 (이전 청크 끝 N 토큰을 다음 청크 앞에 prepend)
    """
```

> 단락 경계 보존이 우선 — `\n\n`로 자연 분리되는 KSPO 게시판 본문은 대부분 단락 1~2개로 끝남. 어절 단위까지 가는 케이스는 매우 드물어야 함.

### Chunk ID (`ids.py`) — `03_chunk_embed_qdrant.md` §3.6

```python
import hashlib
import uuid

NAMESPACE_KSPO = uuid.UUID("8c2a6e2e-0a3f-4b7d-9c54-1f1c5a2e1b00")


def chunk_id_sha1(
    page_id: int, embedding_version: int, chunk_index: int,
    is_attachment: bool, attachment_id: int | None,
) -> str:
    s = f"{page_id}|{embedding_version}|{chunk_index}|{int(is_attachment)}|{attachment_id or 0}"
    return hashlib.sha1(s.encode()).hexdigest()


def to_qdrant_point_id(sha1_hex: str) -> uuid.UUID:
    return uuid.uuid5(NAMESPACE_KSPO, sha1_hex)
```

### Chunker 메인 (`chunker.py`)

```python
@dataclass
class Chunk:
    chunk_index: int
    text: str                     # 헤더 + 본문 (Qdrant page_content가 됨)
    token_len: int
    chunk_id_sha1: str
    qdrant_point_id: UUID
    is_attachment: bool
    attachment_id: int | None


@dataclass
class ChunkInput:
    page_id: int
    embedding_version: int
    domain_host: str
    title: str | None
    posted_at: datetime | None
    summary: str | None
    body_text: str                # refined_text


def chunk_page(inp: ChunkInput) -> list[Chunk]:
    header = build_page_header(PageHeaderInput(
        title=inp.title, domain_host=inp.domain_host,
        posted_at=inp.posted_at, summary=inp.summary,
    ))
    body_tokens = count_tokens(inp.body_text)

    if body_tokens > settings.chunk_long_threshold_tokens:
        bodies = window_split(
            inp.body_text,
            target=settings.chunk_target_tokens,
            overlap=settings.chunk_overlap_tokens,
        )
    else:
        bodies = [inp.body_text]

    out: list[Chunk] = []
    for idx, body in enumerate(bodies):
        text = header + body
        sha1 = chunk_id_sha1(inp.page_id, inp.embedding_version, idx, False, None)
        out.append(Chunk(
            chunk_index=idx, text=text, token_len=count_tokens(text),
            chunk_id_sha1=sha1, qdrant_point_id=to_qdrant_point_id(sha1),
            is_attachment=False, attachment_id=None,
        ))
    return out
```

### 테스트

`test_chunk_tokens.py` (≥4):
- 한국어 짧은 텍스트 토큰 수 (확인된 값)
- LRU 캐시 작동 (인코더 1회만 로드)

`test_chunk_header.py` (≥6):
- 모든 필드 채워짐 → 4줄 헤더 + 본문 구분선
- posted_at None → 게시일 라인 생략
- summary None → 요약 라인 생략
- title None → 제목 라인 생략 (도메인만 남음)
- 첨부 헤더 — file_name 단독
- 첨부 헤더 — parent 정보 포함

`test_chunk_window_split.py` (≥6):
- 800 토큰 이하 → 단일 청크
- 1500 토큰 단락 1개 → 줄/문장 단위로 분할되어 ~600씩 청크
- 5000 토큰 → ~8청크 (overlap 80 반영)
- overlap 검증 — 청크[i] 끝 80토큰이 청크[i+1] 앞에 등장
- 단락 경계 보존 — `\n\n` 위치에서 우선 분할

`test_chunk_ids.py` (≥4):
- 동일 입력 → 동일 sha1 + 동일 uuid
- chunk_index 다르면 다른 sha1
- attachment_id None vs 0 — 동일 처리(`{attachment_id or 0}` → "0")
- uuid5는 NAMESPACE_KSPO 기반

`test_chunker.py` (≥6):
- 짧은 페이지 → 청크 1개, header + body 형태
- 긴 페이지 → 다중 청크, 모두 동일 헤더 prepend
- 첨부 청크 — `is_attachment=True`, `attachment_id` 채워짐
- token_len이 헤더 포함 길이로 계산
- chunks.jsonl 파일 생성
- 동일 입력 재호출 → 동일 chunk_id_sha1 (idempotent)
