# M0.T0.1 — FastAPI 최소 골격 + 프록시·예산 환경변수

## Goal

`src/kspo_ingest/` 패키지를 만들고 settings · logger · db engine · FastAPI app factory의 최소 골격을 구현. `/healthz`와 `/readyz`가 동작.

**v2.1 추가 사항**:
- 사내 프록시 환경변수(`HTTPS_PROXY`/`HTTP_PROXY`/`NO_PROXY`) 검증 — 기동 시 로그
- 월 LLM 예산(`OPENAI_MONTHLY_BUDGET_KRW`) settings 추가 — M5.T5.1에서 사용
- `QDRANT_URL` 기본값을 듀얼모드 개발용(`http://qdrant:6333`)으로 변경

## Spec

### `.env.example` 추가 블록

```bash
# =========================
#  사내 프록시 (KSPO 인프라팀 제공값으로 교체)
# =========================
# api / worker 컨테이너만 적용. nginx·postgres·redis·qdrant는 적용 X.
# OpenAI(refine, embed) 호출이 사내망을 통해 외부로 나갈 때 사용.
HTTPS_PROXY=
HTTP_PROXY=
NO_PROXY=localhost,127.0.0.1,postgres,redis,qdrant,host.docker.internal

# =========================
#  비용 한도
# =========================
# 월 LLM 누계 80% 도달 시 알림(05_devops_ops.md §5.7). 정지는 하지 않음.
OPENAI_MONTHLY_BUDGET_KRW=150000
```

`QDRANT_URL` 라인은 듀얼모드 개발 기본값으로 변경:
```bash
# 개발/파일럿: 본 Compose의 qdrant 컨테이너
# 정식 운영: Tiledesk 외부 인스턴스 (PoC P1~P4 재검증 후 전환)
QDRANT_URL=http://qdrant:6333
```

### `settings.py` (pydantic-settings)

```python
from pydantic_settings import BaseSettings, SettingsConfigDict

class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", extra="ignore")

    app_env: str = "development"
    app_port: int = 8080
    timezone: str = "Asia/Seoul"

    admin_username: str = "admin"
    admin_password_bcrypt: str
    session_secret: str

    postgres_host: str = "postgres"
    postgres_port: int = 5432
    postgres_db: str = "kspo_ingest"
    postgres_user: str
    postgres_password: str

    redis_url: str = "redis://redis:6379/0"

    openai_api_key: str = ""
    openai_refine_model: str = "gpt-5.4-mini"
    openai_embed_model: str = "text-embedding-3-large"
    openai_monthly_budget_krw: int = 150_000      # v2.1

    # 듀얼모드 — 개발/파일럿은 컨테이너, 정식은 Tiledesk 외부
    qdrant_url: str = "http://qdrant:6333"
    qdrant_api_key: str = ""
    qdrant_index_name: str = "tilellm"
    kb_namespace: str = "kspo"
    embedding_version: int = 1

    # 사내 프록시 (api/worker만 적용 — Compose env로 주입) — v2.1
    https_proxy: str = ""
    http_proxy: str = ""
    no_proxy: str = "localhost,127.0.0.1,postgres,redis,qdrant,host.docker.internal"

    log_level: str = "INFO"
    log_format: str = "json"
    alembic_auto: bool = False

settings = Settings()
```

### `logger.py` (loguru JSON)

- stderr JSON 1줄/이벤트
- 의무 필드: `ts, level, service, logger, request_id?, event?`
- uvicorn·sqlalchemy 표준 로거를 loguru로 라우팅
- 본문 텍스트 출력 금지 — 길이/해시만

`get_logger(service: str, logger_name: str)` 제공.

기동 시 1회 INFO 로그 — 프록시 설정 가시화 (값 마스킹은 host:port만 노출):
```
event=startup_proxy https_proxy="proxy.kspo.local:8080" no_proxy="localhost,127.0.0.1,..."
```
값이 비어있으면 `https_proxy=""` 그대로 — 운영자가 누락 인지 가능.

### `db/engine.py`

```python
from sqlalchemy.ext.asyncio import create_async_engine

def make_engine(s):
    dsn = (f"postgresql+asyncpg://{s.postgres_user}:{s.postgres_password}"
           f"@{s.postgres_host}:{s.postgres_port}/{s.postgres_db}")
    return create_async_engine(dsn, pool_pre_ping=True)
```

### `api/main.py` (앱 팩토리)

```python
def create_app() -> FastAPI:
    app = FastAPI(title="kspo-ingest", version="0.2.0",
                  docs_url="/docs", redoc_url="/redoc")
    app.add_middleware(RequestIdMiddleware)
    app.include_router(health.router)
    return app

app = create_app()
```

`@app.on_event("startup")` 에서 `logger.info("startup_proxy", https_proxy=..., no_proxy=...)` 1회 호출.

### `api/middleware.py`

`X-Request-Id` 미들웨어:
- 요청 헤더에 있으면 사용, 없으면 uuid4 hex 생성
- contextvars(`request_id_var`)에 저장 → logger가 읽음
- 응답에 `X-Request-Id` 헤더 부여

### `api/routers/health.py`

```python
@router.get("/healthz")
async def healthz():
    return {"ok": True}

@router.get("/readyz")
async def readyz():
    return {
        "db": await ping_pg_or_503(),
        "redis": "stub",            # M2에서 활성
        "qdrant_dim": "stub",       # M3에서 활성
        "proxy_configured": bool(settings.https_proxy),
    }
```

본 Task는 PG 핑만 실제 구현. PG 실패 시 503.
