## Spec

### 인코딩 탐지 (`encoding.py`) — `02_pipeline.md` §2.9

5단계 우선순위:

```python
def detect_encoding(raw: bytes, content_type: str | None) -> str:
    # 1) HTTP Content-Type charset=...
    if content_type and "charset=" in content_type.lower():
        enc = content_type.split("charset=")[-1].split(";")[0].strip()
        if _try_decode(raw, enc): return enc

    # 2) <meta charset="..."> (HTML 앞 4KB만 ASCII로 sniff)
    head = raw[:4096].decode("ascii", errors="ignore")
    m = re.search(r'<meta[^>]+charset=["\']?([\w-]+)', head, re.IGNORECASE)
    if m and _try_decode(raw, m.group(1)): return m.group(1)

    # 3) BOM
    if raw.startswith(b"\xef\xbb\xbf"): return "utf-8-sig"
    if raw.startswith((b"\xff\xfe", b"\xfe\xff")): return "utf-16"

    # 4) charset_normalizer 추정
    from charset_normalizer import from_bytes
    best = from_bytes(raw).best()
    if best and best.encoding: return best.encoding

    # 5) '?' 비율 임계 초과 시 EUC-KR/CP949 재시도
    text = raw.decode("utf-8", errors="replace")
    if text.count("?") / max(len(text), 1) > 0.05:
        for enc in ("euc-kr", "cp949"):
            if _try_decode(raw, enc): return enc

    return "utf-8"  # fallback
```

### 본문 추출 (`extractor.py`) — `02_pipeline.md` §2.8

4단 우선순위. 첫 단계가 충분한 본문을 반환하면 (>= MIN_BODY_LEN_FOR_ACCEPT) 다음 단계 생략.

```python
MIN_BODY_LEN_FOR_ACCEPT = 200   # 글자 수 — 이보다 짧으면 다음 단계 시도

@dataclass
class ExtractionResult:
    title: str | None
    body_text: str
    method: Literal["main_article", "trafilatura", "readability", "heuristic"]
    raw_html_decoded: str       # 인코딩 디코딩 후 HTML (T2.4가 storage/raw/에 저장)


def extract(raw: bytes, content_type: str | None, *, blacklist: list[str]) -> ExtractionResult:
    encoding = detect_encoding(raw, content_type)
    html = raw.decode(encoding, errors="replace")

    # 1) <main>/<article>/role=main
    body = _try_main_article(html)
    if body and len(body) >= MIN_BODY_LEN_FOR_ACCEPT:
        return ExtractionResult(_extract_title(html), body, "main_article", html)

    # 2) Trafilatura
    body = _try_trafilatura(html)
    if body and len(body) >= MIN_BODY_LEN_FOR_ACCEPT:
        return ExtractionResult(_extract_title(html), body, "trafilatura", html)

    # 3) Readability-lxml
    body = _try_readability(html)
    if body and len(body) >= MIN_BODY_LEN_FOR_ACCEPT:
        return ExtractionResult(_extract_title(html), body, "readability", html)

    # 4) 휴리스틱 (텍스트 밀도)
    body = _try_density(html)
    return ExtractionResult(_extract_title(html), body or "", "heuristic", html)
```

각 추출기는 호출 전 selector blacklist 적용 (선택자에 매칭되는 노드 제거 후 텍스트화).

후처리(공통, 본문 텍스트):
- `re.sub(r'\s+', ' ', text)` — 공백 압축
- 단락 경계는 `\n\n`로 보존 (selectolax `inner_text` 사용 시 적절히)
- 비가시 문자(`​`, `﻿`, `\xa0`) 제거
- 표 → 파이프 텍스트 (`<tr>` → `\n`, `<td>` → ` | `)

### Selector blacklist (`selectors.py`) — `02_pipeline.md` §2.10

`configs/selectors.yaml`은 §2.10 그대로 (header/nav/footer/aside/.gnb/.lnb/.snb/.breadcrumb/.share/.popular/.copyright/.paging/script/style/noscript 등 28종):

```python
def apply_blacklist(html: str, global_selectors: list[str], domain_selectors: list[str] | None) -> str:
    """selectolax로 모든 selector 매칭 노드 .decompose(). 결과 HTML 반환."""
    from selectolax.parser import HTMLParser
    tree = HTMLParser(html)
    selectors = [*global_selectors, *(domain_selectors or [])]
    for sel in selectors:
        for node in tree.css(sel):
            node.decompose()
    return tree.html
```

### Content hash (`hash.py`) — `02_pipeline.md` §2.11

```python
def normalize_for_hash(text: str) -> str:
    s = re.sub(r'\s+', ' ', text).strip()
    s = re.sub(r'조회수\s*[:：]?\s*\d[,\d]*', '', s)
    s = re.sub(r'오늘\s*날짜\s*[:：]?.*?(?=\s|$)', '', s)
    return hashlib.sha256(s.encode("utf-8")).hexdigest()
```

`pages.content_hash` 미변경 시 LLM·임베딩 단계 skip 결정에 사용 (T4.1 incremental).
