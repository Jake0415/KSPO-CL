# M3.T3.3 ⭐ — Qdrant Direct Adapter (듀얼 모드)

## Goal

T3.2의 `EmbeddedChunk` 리스트를 받아 Qdrant 컬렉션에 Direct upsert. **`QDRANT_URL` 환경변수 토글로 자체 컨테이너(개발/파일럿) ↔ Tiledesk 외부(정식 운영) 전환** — 코드 변경 없이 동일 어댑터로 동작. Tiledesk-LLM `/api/ingestion`은 사용하지 않음 (CLAUDE.md 절대 금지).

본 Task가 완료되면 KSPO 본사이트 1 페이지가 INDEXED 상태에 도달하고 자체 Qdrant에 청크가 적재된다.

## v2.1 핵심 결정 — 듀얼 모드

| 단계 | `QDRANT_URL` | `QDRANT_INDEX_NAME` | 동작 |
|---|---|---|---|
| 개발/테스트/PoC/파일럿 | `http://qdrant:6333` (compose 내부) | `kspo_dev` (임의) | 자체 컨테이너에 컬렉션 자동 생성 |
| 정식 운영 | KSPO·Tiledesk 측 제공값 | Tiledesk가 사용하는 `index_name` (예 `tilellm`) | 기존 컬렉션 사용. 차원·payload 컨벤션이 PoC와 다르면 어댑터 보정 |

**전환 절차** (PRD §4.2):
1. PoC P1~P4 재검증 의무
2. `.env`의 `QDRANT_URL` 변경 → `docker compose restart api worker`
3. 자체 `qdrant` 서비스·볼륨 삭제 → 5 services
4. `full` Job 재실행으로 Tiledesk 컬렉션 채우기

본 어댑터는 `QDRANT_URL`만 바꾸면 양쪽 모드 모두 동작해야 한다 — 코드 분기 금지.

## Spec

### 클라이언트 (`client.py`)

```python
from qdrant_client import AsyncQdrantClient


_client: AsyncQdrantClient | None = None


def get_client() -> AsyncQdrantClient:
    """singleton. settings.qdrant_url + settings.qdrant_api_key.

    HTTP timeout: 30s. 첫 호출 시 connection 가능성 검증 + INFO 로그:
      event=qdrant_connect url=http://qdrant:6333 mode=self_hosted|external
    mode 판별: url에 'qdrant' (compose service name) 포함이면 self_hosted, 그 외 external.
    """
    global _client
    if _client is None:
        _client = AsyncQdrantClient(url=settings.qdrant_url, api_key=settings.qdrant_api_key or None, timeout=30.0)
        logger.info("qdrant_connect", url=settings.qdrant_url, mode=_mode())
    return _client
```

### Bootstrap (`bootstrap.py`)

```python
EXPECTED_DIM = 3072        # text-embedding-3-large


async def ensure_collection() -> CollectionStatus:
    """
    1. exists check
    2. 미존재: 자체 컨테이너 모드라면 생성 (Cosine + on_disk + int8 quantization)
              외부 모드라면 ERROR 로그 + raise (Tiledesk 측이 만들어야 함)
    3. 존재: 차원 검증
       - dim != 3072: KSPO-KB-VALIDATION-DIM 에러 → /readyz 503 + 운영자 알림 (런북 A)
       - payload 인덱스 누락: WARN 로그 (자체 컨테이너 모드에서만 자동 생성)
    """


@dataclass
class CollectionStatus:
    exists: bool
    dim: int | None
    points_count: int | None
    healthy: bool                         # /readyz qdrant_dim 응답에 사용
    error: str | None = None
```

`/readyz` 응답:
```python
{
  "db": "ok",
  "redis": "ok",
  "qdrant_dim": 3072 if status.healthy else 0,   # 0 or mismatch → 503
  "qdrant_mode": "self_hosted" or "external",
  "proxy_configured": bool(settings.https_proxy),
}
```

### Tags (`tags.py`) — `03_chunk_embed_qdrant.md` §3.10

```python
def build_tags(*, domain_host: str, posted_at: datetime | None,
               attachment_id: int | None, parent_page_id: int | None,
               is_attachment: bool, embedding_version: int) -> list[str]:
    tags = [
        f"d:{domain_host}",
        f"is_att:{int(is_attachment)}",
        f"v:{embedding_version}",
    ]
    if posted_at:
        tags.append(f"p:{posted_at.year}")
        tags.append(f"p:{posted_at.year}-{posted_at.month:02d}")
    if attachment_id is not None:
        tags.append(f"att:{attachment_id}")
    if parent_page_id is not None:
        tags.append(f"pid:{parent_page_id}")
    return tags
```

### Payload 빌더 (`payload.py`) — `§3.9`

```python
@dataclass
class PayloadInput:
    chunk_id_sha1: str
    text_with_header: str             # page_content
    source_url: str
    domain_host: str
    title: str | None
    summary: str | None
    keywords: list[str]
    posted_at: datetime | None
    is_attachment: bool
    attachment_id: int | None
    attachment_name: str | None
    attachment_download_url: str | None
    parent_page_id: int | None
    parent_page_url: str | None
    embedding_version: int


def build_payload(p: PayloadInput) -> dict:
    """
    LangChain Qdrant 어댑터 표준 가정 — page_content + metadata{...}.
    PoC #1 결과로 키 컨벤션이 다르면 본 함수만 수정.
    """
    return {
        "page_content": p.text_with_header,
        "metadata": {
            "id": p.chunk_id_sha1,
            "source": p.source_url,
            "namespace": settings.kb_namespace,           # "kspo"
            "type": "text",
            "domain_host": p.domain_host,
            "title": p.title,
            "summary": p.summary,
            "keywords": p.keywords,
            "posted_at": p.posted_at.isoformat() if p.posted_at else None,
            "last_indexed_at": datetime.now(timezone.utc).isoformat(),
            "is_attachment": p.is_attachment,
            "attachment_id": p.attachment_id,
            "attachment_name": p.attachment_name,
            "attachment_download_url": p.attachment_download_url,
            "parent_page_id": p.parent_page_id,
            "parent_page_url": p.parent_page_url,
            "embedding_version": p.embedding_version,
            "tags": build_tags(
                domain_host=p.domain_host, posted_at=p.posted_at,
                attachment_id=p.attachment_id, parent_page_id=p.parent_page_id,
                is_attachment=p.is_attachment, embedding_version=p.embedding_version,
            ),
        },
    }
```

### Adapter (`adapter.py`) — `§3.12`

```python
@dataclass
class UpsertResult:
    upserted: int
    elapsed_ms: int


@dataclass
class SyncResult:
    """replace_page_chunks 결과 — diff 정보."""
    upserted: int
    deleted: int


class QdrantDirectAdapter:
    namespace = "kspo"

    def __init__(self):
        self.client = get_client()
        self.collection = settings.qdrant_index_name

    async def ensure_collection(self) -> CollectionStatus:
        return await ensure_collection()

    async def upsert_chunks(self, points: list[EmbeddedChunkWithPayload]) -> UpsertResult:
        """qdrant_client.async_qdrant_client.AsyncQdrantClient.upsert(...) 호출."""

    async def delete_by_ids(self, point_ids: list[UUID]) -> None: ...

    async def delete_by_domain(self, domain_host: str) -> int:
        """filter delete — metadata.domain_host == domain_host. 반환: 삭제 수.

        도메인 DELETE API에서 호출 (M1.T1.3 TODO 결선)."""

    async def replace_page_chunks(
        self, page_id: int, embedding_version: int, new_points: list[EmbeddedChunkWithPayload],
    ) -> SyncResult:
        """`§3.14` 청크 동기화.
        1) 기존 PG chunks (page_id, version) 조회 → 옛 qdrant_point_id set
        2) 새 set과 diff: 신규 upsert / 사라진 delete / 동일 id는 자연 갱신
        3) PG chunks도 새 set으로 replace
        """
```

### `chunks.kb_status` 갱신

upsert 성공 시 PG `chunks.kb_status='OK'` + `pages.status='INDEXED'` + `pages.last_indexed_at=now()`.
실패 시 `kb_status='ERROR'` + 다음 incremental 재시도(M4.T4.1).

### 테스트

`test_qdrant_payload.py` (≥6):
- 모든 필드 채워짐 → 스키마 일치
- posted_at None → metadata.posted_at == None (키 유지)
- is_attachment=False → attachment_* 모두 None
- is_attachment=True + attachment_id 채워짐 → attachment_* 채워짐
- last_indexed_at은 now() 근처
- namespace == "kspo"

`test_qdrant_tags.py` (≥6):
- 페이지 청크: `d:`, `is_att:0`, `v:1` + 선택 `p:YYYY`, `p:YYYY-MM`
- 첨부 청크: `d:`, `is_att:1`, `v:1`, `att:N`, `pid:N`
- posted_at None → `p:` prefix 없음
- 월은 zero-padded (`p:2026-04`, not `p:2026-4`)
- 순서는 결정적이어야 함 (테스트에서 비교 가능)
- v2.1 한정 — Tier 2 prefix 미포함
