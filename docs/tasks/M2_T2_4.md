# M2.T2.4 — ARQ Job 관리 (chain + crawl_jobs 라이프사이클 + Job stats)

## Goal

T2.1~T2.3을 ARQ task로 결선하여 한 페이지가 `DISCOVERED → FETCHED → CLEANED → REFINED|DROPPED` 라이프사이클을 완주. 도메인 레벨 Job(`crawl_jobs`)의 `PENDING → RUNNING → SUCCESS|FAILED|CANCELLED` 상태 머신 + `stats` JSONB 누계.

**M2 종료 Task** — 머지 후 KSPO 본사이트 1 페이지가 REFINED 또는 DROPPED 상태에 도달할 수 있어야 함.

## Spec

### Job 상태 머신

```
crawl_jobs.status:
  PENDING ─(worker pickup)→ RUNNING ─(완료)→ SUCCESS
                              │
                              ├─(취소 요청)→ CANCELLED
                              └─(치명 오류)→ FAILED

pages.status (페이지 단위):
  DISCOVERED ─(fetch)→ FETCHED ─(clean)→ CLEANED ─(refine)→ REFINED
                  │                            │                  │
                  ├──(4xx/5xx)→ ERROR          ├─(no_change)→ SKIPPED
                  │                            └─(pre_rule)→ DROPPED
                  └──(robots disallow)→ DROPPED
```

### Job stats JSONB 스키마

```python
{
    "discovered": 0,
    "fetched": 0,
    "skipped": 0,        # content_hash 미변경 (incremental)
    "refined": 0,
    "dropped": 0,
    "indexed": 0,        # M3에서 +1 (본 Task는 0 유지)
    "errors": 0,
    "drop_reasons": {"too_short": 0, "error_page": 0, "non_korean": 0, "robots": 0},
    "started_at": "...",
    "elapsed_seconds": 0,
}
```

`crawl_jobs.stats`에 누계 저장. ARQ task가 끝날 때마다 `UPDATE crawl_jobs SET stats = stats || '{...}' WHERE id=?` (PG JSONB merge).

> **동시성**: 단일 worker(M5까지) 가정이라 race condition 없음. 다중 worker 도입 시 SELECT ... FOR UPDATE 또는 PG advisory lock 도입(Tier 2).

### Jobs lifecycle (`tasks/jobs.py`)

```python
async def start_job(s: AsyncSession, job_id: int) -> None:
    """status PENDING → RUNNING + started_at = now()"""

async def finish_job(s: AsyncSession, job_id: int, *, status: str, error: str | None = None) -> None:
    """SUCCESS|FAILED|CANCELLED + finished_at = now() + error_message"""

async def is_cancelled(s: AsyncSession, job_id: int) -> bool:
    """worker가 매 task 시작 시 호출 — True면 task 종료"""

async def bump_stats(s: AsyncSession, job_id: int, **delta) -> None:
    """stats JSONB 누계 갱신 (atomic UPDATE)"""
```

### ARQ tasks (`tasks/pipeline/*.py`)

각 task는 (1) cancellation 체크 → (2) 본 작업 → (3) stats 갱신 → (4) 다음 task enqueue 패턴.

```python
async def fetch_page(ctx, *, job_id: int, domain_id: int, url: str, depth: int) -> None:
    s: AsyncSession = ctx["session_factory"]()
    if await is_cancelled(s, job_id):
        return

    # 1) page row upsert (DISCOVERED)
    page = await upsert_page(s, domain_id=domain_id, url=url, depth=depth)

    # 2) robots 체크
    if not await ctx["robots"].is_allowed(url, settings.crawl_user_agent_default):
        await mark_dropped(s, page.id, reason="robots")
        await bump_stats(s, job_id, dropped=1, drop_reasons__robots=1)
        return

    # 3) rate limit acquire
    domain = await get_domain(s, domain_id)
    await ctx["rate_limit"].acquire_token(domain.host, float(domain.rate_limit_rps))

    # 4) fetch
    try:
        result = await ctx["fetcher"].fetch(url, user_agent=domain.user_agent or settings.crawl_user_agent_default)
    except Exception as e:
        await mark_error(s, page.id, error=str(e))
        await bump_stats(s, job_id, errors=1)
        return

    # 5) storage/raw 저장 + page row 업데이트 (FETCHED)
    await save_raw(...)
    await mark_fetched(s, page.id, http_status=result.http_status, content_type=result.content_type)
    await bump_stats(s, job_id, fetched=1)

    # 6) 다음 단계 enqueue
    await ctx["arq"].enqueue_job("clean_page", job_id=job_id, page_id=page.id)
    await ctx["arq"].enqueue_job("extract_links", job_id=job_id, page_id=page.id, html=result.raw_bytes, depth=depth)
```

`clean_page` → `extract` 호출 → 결과 비교 → 변경 시 `refine_page` enqueue, 미변경 시 SKIPPED.
`refine_page` → `refine_page()` 호출 → DROPPED 또는 REFINED.
`extract_links` → `<a href>` 수집 → frontier에 push (depth+1) — `domain.max_depth`/`max_pages` 상한 검증.

### enqueue_seeds (`tasks/pipeline/enqueue_seeds.py`)

```python
async def enqueue_seeds(ctx, *, job_id: int, domain_id: int) -> None:
    """full Job 진입점 — domain의 root URL을 frontier에 넣고 fetch_page 호출 시작.

    1. start_job(job_id) → RUNNING
    2. seed_url = f"{domain.scheme}://{domain.host}/" 정규화
    3. frontier.enqueue + bump_stats(discovered=1)
    4. fetch_page enqueue
    """
```

### Worker settings (`tasks/worker.py`)

```python
from arq.connections import RedisSettings


class WorkerSettings:
    redis_settings = RedisSettings.from_dsn(settings.redis_url)
    functions = [enqueue_seeds, fetch_page, clean_page, refine_page, extract_links]
    queue_name = "default"
    max_jobs = settings.worker_concurrency
    max_tries = 5
    job_timeout = 600   # 10분 — 단일 페이지 fetch~refine 합계 상한

    @staticmethod
    async def on_startup(ctx):
        # session factory + crawl/clean/refine 의존성 주입
        from kspo_ingest.db.session import async_session
        from kspo_ingest.crawl.fetcher import Fetcher
        from kspo_ingest.crawl.robots import RobotsCache
        from kspo_ingest.crawl.frontier import Frontier
        from kspo_ingest.crawl.rate_limit import RateLimit
        ctx["session_factory"] = async_session
        ctx["fetcher"] = Fetcher()
        ctx["robots"] = RobotsCache()
        ctx["frontier"] = Frontier(redis_url=settings.redis_url)
        ctx["rate_limit"] = RateLimit(redis_url=settings.redis_url)
```

### Job API (`api/routers/jobs.py`)

| Method | Path | 응답 |
|---|---|---|
| POST | `/api/jobs/full/{domain_id}` | 201 + `{job_id, arq_job_id}` |
| GET | `/api/jobs?domain_id=&status=&limit=&offset=` | `[JobOut]` |
| GET | `/api/jobs/{id}` | `JobOut` (stats 포함) |
| POST | `/api/jobs/{id}/cancel` | 204 (status=CANCELLED, worker는 다음 tick에 종료) |

> `POST /api/jobs/incremental/{domain_id}`와 `/api/jobs/refresh-url`은 M4(T4.1, T4.2)에서. 본 Task는 `full`만.

```python
@router.post("/full/{domain_id}", response_model=JobOut, status_code=201)
async def trigger_full_job(domain_id: int, s: AsyncSession = SessionDep, _admin=AdminDep):
    domain = await s.get(Domain, domain_id)
    if domain is None or not domain.is_active:
        raise HTTPException(404, "domain not found or inactive")
    job = CrawlJob(domain_id=domain_id, job_type="full", status="PENDING",
                   triggered_by="admin", stats={"discovered": 0, ...})
    s.add(job); await s.commit(); await s.refresh(job)

    pool = await get_arq_pool()
    arq_job = await pool.enqueue_job("enqueue_seeds", job_id=job.id, domain_id=domain_id)
    job.arq_job_id = arq_job.job_id
    await s.commit()
    return job
```
