# M0.T0.4 — Frontend bootstrap (Vite + React + Tailwind + design-system)

## Goal

`web/` 폴더에 Vite + React 18 + TypeScript + Tailwind + shadcn/ui 기반 SPA 스캐폴딩. `design-system/`의 토큰을 적용하고, AppShell + 5 라우트 스텁(빈 페이지)을 만든다.

T0.2가 만든 `Dockerfile.web` + nginx가 placeholder 대신 실제 React 빌드 산출물을 서빙하게 됨. **M0 종료 Task** — 머지 후 M1 진입 가능.

## v2.1 핵심 결정 (CLAUDE.md / design-system/CLAUDE.md)

- **Admin UI = React + Tailwind + shadcn/ui + lucide-react SPA**. Jinja2/HTMX 미사용.
- 시각 어휘는 `design-system/` 단일 진실원 — Primary `#155DFC`, 카드 radius 12, 보더 `#E2E8F0`
- 라우터: React Router v6
- 데이터 페칭: TanStack Query (M1.T1.5에서 실제 호출. 본 Task는 클라이언트 init만)
- 폰트: Pretendard → Inter, Geist Mono(코드)

### `web/src/lib/api.ts`

```ts
export async function apiFetch<T>(path: string, init?: RequestInit): Promise<T> {
  const res = await fetch(path, { credentials: 'include', ...init });
  if (res.status === 401) {
    if (location.pathname !== '/login') location.href = '/login';
    throw new Error('unauthorized');
  }
  if (!res.ok) throw new Error(`${res.status} ${res.statusText}`);
  return res.json();
}
```

### `Dockerfile.web` 정리

T0.2의 placeholder 회피 로직(`|| true`, `|| mkdir`) 제거. 정식 빌드:

```dockerfile
FROM node:20-alpine AS build
WORKDIR /app
COPY web/package.json web/package-lock.json ./
RUN npm ci
COPY web/ ./
COPY design-system/ ../design-system/
RUN npm run build

FROM nginx:1.27-alpine
ENV TZ=Asia/Seoul
RUN apk add --no-cache tzdata && cp /usr/share/zoneinfo/$TZ /etc/localtime
COPY --from=build /app/dist /usr/share/nginx/html
COPY docker/nginx/nginx.conf /etc/nginx/nginx.conf
EXPOSE 80 443
```

> `design-system/`을 빌드 컨텍스트에 포함시켜 `tailwind.config.js`의 상대 import가 동작하게 함. compose `context: ..` (프로젝트 루트)이라 가능.

### CI에 frontend step 추가

`.github/workflows/ci.yml`의 `lint-test` job 끝에 또는 별도 job:

```yaml
  web:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '20', cache: 'npm', cache-dependency-path: web/package-lock.json }
      - working-directory: web
        run: |
          npm ci
          npm run lint
          npm run build
```
