# M1.T1.4 — Admin 인증 (HTTP Basic → 세션 쿠키)

## Goal

단일 Admin HTTP Basic 로그인 → 8시간 만료 세션 쿠키 발급. `/api/*` 모든 보호 경로(domains, jobs, pages)는 세션 검증을 통과해야 200; 미인증 시 401. `/healthz`, `/readyz`, `/files/*`, `/login`, `/api/auth/*`, `/docs`, `/openapi.json`은 화이트리스트.

T1.3의 `require_admin` placeholder를 실제 세션 검증으로 교체.

## Spec

### 인증 흐름

```
1. 클라이언트가 POST /api/auth/login 으로 username/password (form-urlencoded) 전송
2. 서버: passlib bcrypt verify (cost ≥ 12)
   - 실패 → 401 + {"error":"invalid_credentials"}
   - 성공 → Starlette SessionMiddleware의 request.session["admin"] = {"u": username, "iat": ts} 설정
3. 응답에 Set-Cookie: session=...; HttpOnly; SameSite=Lax; Max-Age=28800
4. 이후 모든 보호 경로는 require_admin 의존성으로 session 검증
5. POST /api/auth/logout → request.session.clear()
```

> Basic Auth 헤더(`Authorization: Basic ...`)도 보조 수단으로 지원: `require_admin`이 세션 없을 때 헤더를 fallback. 단순 도구·스크립트용. 401 응답에 `WWW-Authenticate: Basic realm="kspo-ingest"`.

### `auth/password.py`

```python
from __future__ import annotations
from passlib.hash import bcrypt


def verify_password(plain: str, bcrypt_hash: str) -> bool:
    try:
        return bcrypt.verify(plain, bcrypt_hash)
    except Exception:
        return False
```

### `auth/session.py`

```python
from __future__ import annotations
from datetime import datetime, timezone

from fastapi import Request

from kspo_ingest.settings import settings


def session_login(request: Request, username: str) -> None:
    request.session["admin"] = {
        "u": username,
        "iat": int(datetime.now(timezone.utc).timestamp()),
    }


def session_logout(request: Request) -> None:
    request.session.pop("admin", None)


def session_user(request: Request) -> str | None:
    sess = request.session.get("admin")
    if not sess:
        return None
    iat = int(sess.get("iat", 0))
    age = int(datetime.now(timezone.utc).timestamp()) - iat
    if age > settings.session_max_age_seconds:
        request.session.pop("admin", None)
        return None
    return sess.get("u")
```

### `api/routers/auth.py`

```python
from __future__ import annotations
import base64

from fastapi import APIRouter, Form, HTTPException, Request, Response, status

from kspo_ingest.api.auth.password import verify_password
from kspo_ingest.api.auth.session import session_login, session_logout, session_user
from kspo_ingest.settings import settings

router = APIRouter(prefix="/api/auth", tags=["auth"])


@router.post("/login")
async def login(
    request: Request,
    username: str = Form(...),
    password: str = Form(...),
):
    if username != settings.admin_username:
        raise HTTPException(401, "invalid_credentials")
    if not verify_password(password, settings.admin_password_bcrypt):
        raise HTTPException(401, "invalid_credentials")
    session_login(request, username)
    return {"ok": True, "username": username}


@router.post("/logout")
async def logout(request: Request) -> Response:
    session_logout(request)
    return Response(status_code=status.HTTP_204_NO_CONTENT)


@router.get("/me")
async def me(request: Request):
    u = session_user(request)
    if u is None:
        # Basic fallback
        auth = request.headers.get("authorization", "")
        if auth.lower().startswith("basic "):
            try:
                raw = base64.b64decode(auth.split(" ", 1)[1]).decode()
                user, _, pw = raw.partition(":")
                if user == settings.admin_username and verify_password(pw, settings.admin_password_bcrypt):
                    return {"username": user, "via": "basic"}
            except Exception:
                pass
        raise HTTPException(401, "unauthenticated")
    return {"username": u, "via": "session"}
```

### `api/deps.py` 수정 — `require_admin` 실제 결선

```python
from fastapi import Depends, HTTPException, Request

from kspo_ingest.api.auth.password import verify_password
from kspo_ingest.api.auth.session import session_user
from kspo_ingest.settings import settings


async def require_admin(request: Request) -> str:
    u = session_user(request)
    if u is not None:
        return u
    # Basic fallback (스크립트/도구용)
    auth = request.headers.get("authorization", "")
    if auth.lower().startswith("basic "):
        import base64
        try:
            raw = base64.b64decode(auth.split(" ", 1)[1]).decode()
            user, _, pw = raw.partition(":")
            if user == settings.admin_username and verify_password(pw, settings.admin_password_bcrypt):
                return user
        except Exception:
            pass
    raise HTTPException(
        status_code=401,
        detail="unauthenticated",
        headers={"WWW-Authenticate": 'Basic realm="kspo-ingest"'},
    )


AdminDep = Depends(require_admin)
```

### `api/main.py` 수정

```python
from starlette.middleware.sessions import SessionMiddleware

def create_app() -> FastAPI:
    app = FastAPI(...)
    app.add_middleware(RequestIdMiddleware)
    app.add_middleware(
        SessionMiddleware,
        secret_key=settings.session_secret,
        session_cookie="session",
        max_age=settings.session_max_age_seconds,
        same_site="lax",
        https_only=settings.app_env == "production",
    )
    app.include_router(health.router)
    app.include_router(auth.router)
    app.include_router(domains.router)
    return app
```

### 화이트리스트 정책

라우터별 의존성으로 결선 — `health.router`와 `auth.router`는 `require_admin` 미사용. 그 외(`domains` 포함)는 모두 `AdminDep`. `/files/*`는 M3에서 별도 라우터로 추가될 때 화이트리스트로 명시.

> 미들웨어 레벨 화이트리스트는 만들지 않음 — FastAPI 의존성으로 충분.

### bcrypt 해시 생성 명령 (운영자 안내)

`README.md` 또는 `CONTRIBUTING.md`의 보안 섹션에 명시:

```sh
python -c "from passlib.hash import bcrypt; import getpass; print(bcrypt.using(rounds=12).hash(getpass.getpass('Admin password: ')))"
```

→ 출력값을 `.env`의 `ADMIN_PASSWORD_BCRYPT`에 붙여넣기.
