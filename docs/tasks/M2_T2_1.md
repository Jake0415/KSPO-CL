## Spec

### URL 정규화 (`url_normalize.py`) — `02_pipeline.md` §2.3

```python
TRACKING_PARAMS = {"utm_source","utm_medium","utm_campaign","utm_term","utm_content","fbclid","gclid","_ga"}
PRESERVE_PARAMS = {"bbsId","nttId","page","mode"}     # KSPO 게시판 식별


def normalize_url(raw: str) -> tuple[str, str]:
    """returns (normalized_url, sha1_hash)"""
    # 1) parse, lower scheme/host
    # 2) drop default ports (80/443)
    # 3) drop fragment
    # 4) path: empty → "/", else preserve trailing slash as-is
    # 5) sort query keys, drop tracking, preserve PRESERVE
    # 6) url_hash = sha1(normalized).hexdigest()  ← 40 chars
```

테스트 (≥10 케이스):
- 트래킹 파라미터 제거: `?utm_source=x&page=2` → `?page=2`
- KSPO 게시판 보존: `?bbsId=N1&nttId=99` 그대로
- 쿼리 정렬: `?b=2&a=1` → `?a=1&b=2`
- fragment 제거: `#top`
- 기본 포트 제거: `https://x.com:443/` → `https://x.com/`
- scheme/host 소문자
- trailing slash 보존
- `?` 만 있으면 제거
- 중복 슬래시 정규화
- 동일 URL은 동일 hash

### Fetcher (`fetcher.py`)

```python
class Fetcher:
    """httpx.AsyncClient(http2=True) wrapper.

    - timeouts: connect=10s, read=30s
    - max_response_bytes=10*1024*1024 (10MB), 초과 시 ResponseTooLarge
    - tenacity: stop_after_attempt(5), wait_exponential(min=1, max=300), retry on 5xx/network
    - Retry-After 헤더 존중
    - 응답에서 charset 결정은 cleaner 책임 (raw bytes만 반환)
    """

    async def fetch(self, url: str, *, user_agent: str) -> FetchResult:
        ...


@dataclass
class FetchResult:
    url: str                # 최종 URL (redirect 후)
    http_status: int
    content_type: str
    raw_bytes: bytes
    headers: dict[str, str]
    elapsed_ms: int
```

본 Task는 fetcher의 raw bytes만 반환 — `pages.last_fetched_at` 갱신·`storage/raw/` 저장은 호출자(T2.4) 책임.

> **로깅**: 본문 텍스트 로그 금지. `event=fetch_ok url_hash=... http_status=200 byte_size=12345 elapsed_ms=234`만.

### Frontier (`frontier.py`)

`02_pipeline.md` §2.4 구조 그대로:

| 키 | 자료구조 | 용도 |
|---|---|---|
| `frontier:{job_id}` | List | 방문 대기 (RPUSH/LPOP — FIFO BFS) |
| `seen:{job_id}` | Set | 등록된 url_hash |
| `inflight:{job_id}` | Set | 처리 중 |
| `host_bucket:{host}` | ZSet | rate limit 토큰 (score=available_at_ts) |

```python
class Frontier:
    async def enqueue(self, job_id: int, url: str, depth: int) -> bool:
        """url_hash가 seen에 없으면 frontier에 push + seen에 add. True/False."""

    async def dequeue(self, job_id: int) -> tuple[str, int] | None:
        """LPOP frontier, inflight에 add. (url, depth) 또는 None."""

    async def ack(self, job_id: int, url_hash: str) -> None:
        """inflight에서 제거."""
```

> **메모리**: KSPO 본사이트가 50,000 페이지 가정 시 frontier+seen ≈ 50k * 평균 80B URL ≈ 4MB. 1 Job 동안만 유지하므로 MVP는 평면 List/Set 충분.

### Rate limit (`rate_limit.py`)

```python
async def acquire_token(host: str, rps: float) -> None:
    """간단한 token bucket — host_bucket ZSet에 'available_at_ts' 1개만 유지.

    - 현재 ts > available_at_ts: 즉시 통과 + ZADD now+1/rps
    - 현재 ts <= available_at_ts: sleep(diff) + ZADD ts+1/rps
```
