## 2. 사이트별 구조 및 크롤 전략

### Tier A: 대형 사이트 (depth 2+ BFS 필수)

#### 국민체육진흥공단 (www.kspo.or.kr)
- **구조**: `contents.do?menuNo=` 정적 콘텐츠 + `bbs/B000xxxx/list.do` 게시판
- **depth 1**: 64 링크 (게시판 34, 목록 16, 콘텐츠 2)
- **depth 2**: +242 링크
- **게시판**: 공지사항, 보도자료, 채용, FAQ, 사업실명제, 기금운용 등 **12개 게시판**
- **게시글 접근**: `<a href="/bbs/B0000006/view.do?nttId=XXX">` — **href 직접 링크** ✅
- **크롤 방법**: httpx BFS. 게시판 상세는 href로 직접 접근 가능
- **예상 페이지**: 1,500~3,000
- **특이사항**: robots.txt `Disallow: /` 이나 서버 비차단

#### KCYCLE경륜 (www.kcycle.or.kr)
- **구조**: SPA 스타일, `/clinic/`, `/guide/`, `/race/` 하위 경로
- **depth 1**: 125 링크 (기타 116, 게시판 7, FAQ 2)
- **depth 2**: +485 링크 — **사이트 최다**
- **게시판**: 경륜가이드, 배당률, 선수정보, 도박상담 FAQ (16,511자)
- **크롤 방법**: httpx BFS (JS 리다이렉트 자동 감지 `/` → `/main`)
- **예상 페이지**: 500~1,000

#### KBOAT경정 (www.kboat.or.kr)
- **구조**: KCYCLE과 동일 구조
- **depth 1**: 118 링크 (기타 109, 게시판 7, FAQ 2)
- **depth 2**: +470 링크
- **크롤 방법**: httpx BFS (JS 리다이렉트 자동 감지)
- **예상 페이지**: 500~1,000

| 기법 | 구현 상태 | 적용 대상 |

| **JS 리다이렉트 감지** (`location.href`) | ✅ 구현 완료 | kcycle, kboat, css |

| **NFA 게시글 상세** (`fnBoardContentView`) | nfa.kspo.or.kr | Playwright JS eval (현재 구현 완료, 통합 크롤에서 검증 필요) |

### 게시판 페이지네이션 미구현 영향

현재 게시판 목록 1페이지(10~20건)만 크롤. 전체 게시판 크롤하려면:

```
/bbs/B0000078/list.do?pageNo=1  → 10건
/bbs/B0000078/list.do?pageNo=2  → 10건
...
/bbs/B0000078/list.do?pageNo=N  → 마지막
```

이 패턴을 자동으로 생성하는 기능이 필요합니다. 3개월 freshness 필터와 결합하면 최신 게시글만 수집 가능.
